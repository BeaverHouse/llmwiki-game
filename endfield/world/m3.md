# M3

M3는 엔드필드 공업의 정예 오퍼레이터다. 최고 기밀, 최고 위험 등급의 전투 임무를 맡으며, [미션 제로](zeroth_directive.md)의 집행자 가운데 한 명이다. 메인 스토리에서 관리자 곁을 지키는 조연으로 나오며, 플레이할 수 있는 오퍼레이터가 아니다(2026-10 기준). 영어 인물 정보는 성별을 여성, 종족을 펠린, 소속을 엔드필드 공업과 미션 제로(과거)로 적는다.

## 기록 속의 M3

| 내용 | 문서 |
|---|---|
| 미션 제로의 수행자(1장 Ⅳ)이자 파일 자료 4의 집행자. 펠리카를 창립자에게 데려간다 | [미션 제로](zeroth_directive.md#파일-자료-4) |
| 관리자, 창립자, 정예 오퍼레이터들과 함께 의사 결정층 원점을 이루었다. 감독관 직위에 관한 말 | [창립자와 원점](founder.md) |
| 창립자와 함께 위기 대책팀을 지휘한 적이 있다 | [위기 대책팀](endfield_staff.md#위기-대책팀) |
| 펠리카 파일 자료 1에 붙은 권한 기록 'M3의 음성 메모' | [리시아](lycia.md#펠리카-파일-자료) |
| 관리자와 함께 와파린의 최초의 오리지늄 연구를 묵인했다 | [리컨비너](reconvener.md#기원) |
| 라스트 라이트 파일 자료 4에서 오래 알고 지낸 세쉬카의 플레밍과 라스트 라이트를 두고 이야기한다. 플레밍은 M3를 카즈델과 인연이 깊다는 필라인으로 여긴다 | [세력](factions.md#플레밍) |

펠리카는 어릴 때 M3를 '언니'라고 불렀다. 대사 'M3에 관하여'에서 펠리카는 최근 몇 년 동안 제강호에서 M3를 거의 보지 못했으며, M3에게 자신만의 특별한 사명이 있기 때문일 것이라고 말한다.

## 메인 스토리

- 1장 끝과 2장 서막: 각 세력 대표 회의 뒤 무릉 대균열에서 적이 움직이기 시작했다고 알리고, 관리자·[진천우](../operators/chen_qianyu.md)와 함께 무릉성으로 향한다([4번 협곡](valley_iv.md#무릉으로)).
- 파운데이션이 여러 분파로 나뉘어 있고, 백여 년 전 관리자가 특수한 방법으로 이들을 초자연으로 몰아냈다고 말한다([파운데이션](foundation.md#추방과-귀환)).
- 2장 Ⅶ: 알레이크레오스가 파운데이션이 만든 병사이며 그의 등장으로 파운데이션이 탈로스2의 좌표를 다시 알게 되었다고 말한다([파운데이션](foundation.md#추방과-귀환)).

## 확인하지 못한 것

- 'M3'라는 이름의 뜻과 M3의 본명, 나이, 출신. 게임 안 기록은 이를 밝히지 않는다.
- 영어 인물 정보가 소속을 '미션 제로(과거)'로 적는 근거. 1장 Ⅳ와 파일 자료 4는 M3를 현재형으로 집행자라 부른다.
- 1장 Ⅳ에서 펠리카가 M3를 '수행자'로 소개하는 대사의 원문.
- M3가 창립자와 함께 관리자를 보조했다는 '과거'가 언제인지.
