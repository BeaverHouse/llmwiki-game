# Arknights: Endfield — 문서 목록

파티·사이클·시너지는 [parties/method.md](parties/method.md)의 절차로 답한다. 규칙은 [systems/interactions.md](systems/interactions.md)·[systems/combat.md](systems/combat.md), 오퍼레이터의 행동은 오퍼레이터 문서의 `## 상호작용 카드`가 근거다. 메인 딜러의 파티 문서(`parties/<오퍼레이터>_party.md`)가 있으면 풀이 예제로 본다. 파티 문서에 없는 조합도 카드로 짜고 판정한다.

## 작성 기준

- 범위: 오퍼레이터, 전투, 지금까지의 스토리, 거점과 생산, 지역, 아이템.
- 오퍼레이터끼리 순위를 매기지 않는다. 수치 차이만 적는다. 유지보수자의 판단도 의견으로 옮겨 적지 않는다. "거의 모든 아츠 파티에 들어간다" 같은 결론은 카드에서 끌어낸다.
- 오퍼레이터 문서: 프로필 → 배경 → 스킬(M3 배율만) → 재능과 잠재능력 → 상호작용 카드 → 무기·장비 → 확인하지 못한 것 → 히스토리. 동작·조건·연계는 카드에만, 편성은 파티 문서에 둔다. 예시 [이본](operators/yvonne.md).
- 카드가 파티·사이클의 정본이다. 다른 부분과 어긋나거나 빠진 사실이 있으면 카드부터 고친다.
- 배경 절은 게임 안 텍스트(소개, 인사 요약서, 파일 자료, 대사)를 기록 단위로 원문에 가깝게 옮긴다. 텍스트에 없는 원인이나 판단을 넣지 않는다. 개방 조건이 있는 기록은 조건을 적고, 보지 못한 기록은 빠졌다고만 적는다.
- 꼬리표, 스킬 사용 시점, 세계관 안의 말은 [AGENTS.md](../AGENTS.md) 3·7절을 따른다. 공식 표기: 四号谷地 4번 협곡, タロⅡ 탈로스2, 超域 초자연, 文明地帯 문명 밴드.
