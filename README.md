# Game LLM Wiki

게임 도메인을 위한 **Self-evolving Live Wiki**입니다. AI 어시스턴트가 답변 근거로 사용하는 지식 베이스이며, AI와 사람이 함께 편집하고 git으로 모든 변경이 추적됩니다.

## 구조

| 폴더           | 도메인                          | 상태                |
| -------------- | ------------------------------- | ------------------- |
| `bluearchive/` | 블루 아카이브 (BA Torment 연동) | 운영 중 (seed 완료) |
| `anothereden/` | 어나더 에덴 (AE Check 연동)     | 준비 중             |
| `endfield/`    | 명일방주: 엔드필드              | 준비 중             |
| `lolpro/`      | LOL (대회 기준)                 | 준비 중             |

각 도메인 폴더에는 `index.md`(문서 목록과 한 줄 요약)와 `log.md`(변경 감사 기록)가 있습니다.

## 역할 분담

이 위키는 하이브리드 지식 베이스의 절반입니다.

- **MCP 도구** (개발자 관리): DB 조회, 계산, 실시간 데이터 — 예: 학생 스탯 계산, 파티 검색
- **LLM Wiki** (이 리포, AI가 평시 관리): 평가·해석·히스토리·서사 등 비정형 지식 — 예: 보스 공략 요령, 메타 변화 기록

## 편집 규칙 (요약)

- `main` 브랜치에 직접 push하지 않습니다. **모든 변경은 PR로** 제출합니다.
- AI가 만드는 PR에는 근거(출처 URL, 피드백 세션 요약)가 본문에 포함되어야 합니다.
- 문서 규격과 수록 기준은 [AGENTS.md](AGENTS.md)를 따릅니다.
- 모든 변경은 해당 도메인의 `log.md`에 한 줄씩 기록합니다.
