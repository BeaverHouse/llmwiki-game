# Another Eden 고유명사 표기 (ko/en/ja)

다른 언어로 답할 때 고유명사는 즉석 번역하지 말고 이 표를 따른다.
"확인" 열: `사이트` = 사이트 데이터(ae_translation)의 표기 / `2차` = 공략 사이트에서만 확인 / `미확인` = 해당 언어 표기를 찾지 못함. 한국어가 `—`인 항목은 사이트 번역표(2026-10-25 전체 대조)에 없는 것으로, [backlog.md](backlog.md)의 "확인 필요"에 올라 있으며, 문서에서는 일본어 그대로 쓴다. 번역표에 있는 캐릭터·버디·속성·무기 종류·특성·클래스·던전·현현·진현현·성도각성·글래스터·이절·개전·경전록은 문서에서 한국어로 쓴다.

스타일 표기: NS(ノーマルスタイル), AS(アナザースタイル), ES(エクストラスタイル)는 이름 뒤 괄호로 붙인다. 예: 질퍼니(AS) = ジルファニー(AS). SA는 성도각성을 마친 상태를 가리킨다.
