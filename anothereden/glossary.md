# Another Eden 고유명사 표기 (ko/en/ja)

다른 언어로 답할 때 고유명사는 즉석 번역하지 말고 이 표를 따른다.
"확인" 열: `사이트` = 사이트 데이터(ae_translation)의 표기 / `2차` = 공략 사이트에서만 확인 / `미확인` = 해당 언어 표기를 찾지 못함. 한국어가 `—`인 항목은 [backlog.md](backlog.md)의 "확인 필요"에 올라 있으며, 문서에서는 일본어 그대로 쓴다.

스타일 표기: NS(ノーマルスタイル), AS(アナザースタイル), ES(エクストラスタイル)는 이름 뒤 괄호로 붙인다. 예: 질퍼니(AS) = ジルファニー(AS). SA는 星導覚醒을 마친 상태를 가리킨다.

## 장비

[guides/meta_equipment.md](guides/meta_equipment.md)의 장비·시리즈명(赫耀, 蒐魔装, 千年樹, エルピス, 亜空, 機械仕掛け, ルーナ, アダマス, ウィズダム, 食器, 禍時, 悠久, スピナル, プリズム, 魔殻, 渡り花, 小判金, プラズマ, スパークル, 竜纏, 射干玉, 背水, 渾身, 精霊の腕輪·首飾り, 개별 무기명)과 「パウルス・ステラ」, 「昏き星の塊」은 모두 한국어·영어 표기를 확인하지 못해 일본어로만 쓴다.

캐릭터 문서(characters/)의 추천 장비·グラスタ·클래스 서적 이름(千年樹の指輪, 竜纏の指輪, 小判金の指輪, ルーナ・バルクス, プリズムソード, 赫耀の槌, 冥鬼の錫杖, アセト・ヴィータ, 紅玉ノ遣イ, 撃陣の力, 共鳴の力, 虚空の力, 増恵の力, 増蝕の力, 癒しの力, 狙い撃つ錬成, 搦手ノ撃, 狂星の力, 真・杖の祈り, 星屑のバッジ, 각 캐릭터의 「〜の書」「〜の異節」「〜の改典」「〜の証」)과 스킬명도 일본어 표기만 확인했다.
