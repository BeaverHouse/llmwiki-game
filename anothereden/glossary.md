# Another Eden 고유명사 표기 (ko/en/ja)

다른 언어로 답할 때 고유명사는 즉석 번역하지 말고 이 표를 따른다.
"확인" 열: `사이트` = 사이트 데이터(ae_translation)의 표기 / `2차` = 공략 사이트에서만 확인 / `미확인` = 해당 언어 표기를 찾지 못함. 한국어가 `—`인 항목은 [backlog.md](backlog.md)의 "확인 필요"에 올라 있으며, 문서에서는 일본어 그대로 쓴다.

스타일 표기: NS(ノーマルスタイル), AS(アナザースタイル), ES(エクストラスタイル)는 이름 뒤 괄호로 붙인다. 예: 질퍼니(AS) = ジルファニー(AS). SA는 星導覚醒을 마친 상태를 가리킨다.

## 장비
