# 그림자 파티 (刻陰陣 편성)

전위를 그림자로 맞추고 刻陰陣(極・刻陰陣, 絶・刻陰陣)을 깔아 싸운다. 刻陰陣은 무속성 외 모든 속성의 피해를 올리지만 AF 게이지 +15는 그림자 공격에만 붙는다([ZONE](zone.md)). [애니](../characters/eni.md)의 「血の誓約」으로 첫 턴을 안전하게 세팅하고, [검은 옷의 칼잡이(AS)](../characters/black_clad_swordsman_as.md)의 絶・刻陰陣으로 아군 전체에 ルナティック<挺身>을 얹는다. 고유명사 표기는 [glossary.md](../glossary.md)를 따른다.

출처 시점: 검은 옷의 칼잡이(AS) 문서(2025-08)는 애니 SA(Ver3.14.0, 2026-01) 전이다.

## ZONE 전개

- 애니의 「ワルプルギスの闇夜」(선제), SA 애니의 전투 시작 刻陰陣(전위 <그림자> 2명 이상), 검은 옷의 칼잡이(AS)의 「アラネアレガート」, 웨네피카의 SB 「イユンクス」(ZONE 파괴 + 極・刻陰陣).
- 絶・刻陰陣: 刻陰陣 중 검은 옷의 칼잡이(AS)가 「ルナティック+」. 共鳴<挺身>이 아군 전체에 ルナティック<挺身>을 주고 통상 공격이 「スケルツァンド」로 바뀐다. 전위 그림자가 2명 이하면 共鳴<挺身> 쌓이는 속도가 반이 된다.

## 편성

### 그림자 속성 파티 (애니 문서, 2026-02)

| 전위 | 후위 |
|---|---|
| 애니 — 서포터 | 큐리오 — 글래스터 담당 |
| 네코코(ES) — 서포터 | 보라 의상의 창술사 — 글래스터 담당 |
| 검은 옷의 칼잡이(AS) — 어태커 | |
| 클러그혼 — 탱커 | |

네코코(ES) 외에는 그림자로 맞춰 천명 게이지 회전과 피해를 중시한다. 네코코(ES)가 없으면 틸릴(ES)이나 투바(ES).

### 그림자 3명형 (검은 옷의 칼잡이(AS) 문서, 2025-08)

| 전위 | 후위 |
|---|---|
| 네코코(ES) — 서포터 | 큐리오 — 글래스터 담당 |
| 웨네피카 — 서브 어태커 | 유인 — 글래스터 담당 |
| 검은 옷의 칼잡이(AS) — 어태커 | |
| 카구라메 — 탱커 | |

그림자 3명으로 共鳴<挺身>을 빨리 쌓아 「アンダンテ」를 돌린다. 웨네피카의 「カターラエヴォギア」로 카구라메의 받는 피해를 줄인다.

### 그림자 2명형 (같은 문서)

위 편성의 카구라메를 알마(AS)(탱커 겸 어태커)로, 유인을 빨간 외투의 화염술사로 바꾼다. 複写 迎撃과 共鳴<挺身>으로 화력에 특화해 단기전에 매우 강하고 장기전에는 밀리기 쉽다. 안정을 원하면 네코코(ES)를 애니로 바꾼다. 「アンダンテ」를 적극적으로 쓰려면 그림자 3명 이상이 낫다.

### 배치

「血の誓約」의 庇立て는 내부 ID가 높은 동료(파티 오른쪽)부터 받는다. 메인 어태커를 맨 오른쪽에 두지 않고, 迎撃·회피 동료를 전위 4번째 칸에 둔다 → [상태 효과](status_effects.md).

## 약점

- ルナティック<挺身>은 耐久·精神을 0으로 만든다. 강한 腕知 디버프가 없으면 한 방에 쓰러진다.
- 애니가 단체 공격을 맞는 것이 가장 큰 구멍이다(HP 배지로 보완). 부활은 애니가 전위에서 행동 가능할 때만 발동한다.
- 守護·踏ん張る가 있으면 「血の誓約」이 소비되지 않아 배리어 관통 부여가 막힐 수 있다.
- 2025-08 시점 SA 그림자 동료가 적어 순수 그림자는 화력·손이 모자라기 쉽다. 검은 옷의 칼잡이(AS) 문서는 그림자 3명 + 다른 속성 출장을 최적해로 본다.
