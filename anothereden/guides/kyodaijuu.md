# 巨大獣 生息地確認リスト

메인 스토리 3부 中編의 猫人世界 プラトノス 필드에 나오는 거대 적 25종이다. 虚神器 「ギルバデス」로만 싸운다. 어느 적을 쓰러뜨렸는지는 歓楽街 トルルタン 「コーミアの工房」의 「巨大獣 生息地確認リスト」에서 본다. 100장부터 ギルバデス로 각 맵에 들어갈 수 있다.

## 쓰러뜨리면 얻는 것

- 처음 쓰러뜨릴 때 ギルバデス 파츠의 레벨을 1 올리는 「グロウコア」가 나온다.
- 대부분은 무장을 여는 「(적 이름)の巨獣核」을 준다(아래 표).
- 쓰러뜨린 종류 수로 파츠 레벨 상한이 풀린다: 5종 Lv50, 9종 Lv60, 16종 Lv80.
- 무장 Ω 강화에 드는 「レアエナジーシード」는 アボモス大陸 거대 적에게서 나온다(댓글, 참고).
- 리스트는 위에서부터 약한 순서로 보인다(추정). 위부터 잡는다.

## 먼저 키울 무장

| 파츠 | 순서 | 이유 |
|---|---|---|
| 코어 | レジストジャマー | 「ルインクエイク」 계열이 적 전체 腕力·知性 30~45%DOWN |
| 암(공격) | エレメントブレイド(β까지) → マナブラスター → ライジングセイバー → デストロイバスター | 스토리는 マナブラスター로 끝난다. 숨은 보스급은 ライジングセイバー·デストロイバスター |
| 암(수비) | ヒールシールド | 挑発 + 자기 회복. エストレアガード보다 일찍 얻는다 |
| 헤드 | ブロックジャマー → リベンジヒーラー → サウンドメイカー | 先制 腕力·知性 DOWN, 踏ん張る 부여, 歌唱 |

파츠 레벨은 스토리 진행이면 코어·암·헤드를 고르게 올린다. 그 밖의 무장은 쓰지 않는다.

## 빠뜨리기 쉬운 것

- No.24 巨煉龍ジェネスヴルム은 서브 이벤트 「9人目の勇者」에서 쓰러뜨려 「ボルトコア」를 얻는다. トレジャーハント와 ニャインズ・オブ・バトル(NOB) 서브 이벤트를 마친 뒤 クー博士の研究所에서 시작하고, 끝내면 버디 휴우가가 가입한다.
- No.25 ラヴォーグ는 서브 이벤트 「赫き流星」의 마지막 싸움 「超巨大結晶生物ラヴォーグ」다. 보상은 [사이러스](../characters/cyrus.md) 전용 「星斬丸」이다 → [赫き流星](akaki_ryuusei.md).
- Ver3.17.0 전에는 ラビリベリア를 쓰러뜨려도 리스트에 討伐済로 뜨지 않는 경우가 있었다.
