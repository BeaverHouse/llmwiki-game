# 찌르기 파티 (瞬突陣 편성)

전위를 창·활 캐릭터로 맞추고 瞬突陣(極・瞬突陣)을 깔아 싸운다. 瞬突陣은 찌르기 1.3배, 그 밖의 공격 0.7배에 AF 게이지가 거의 오르지 않는다([ZONE](zone.md)). 무기 종류로 묶는 파티라 바람·땅·물 캐릭터가 섞인다. 재행동이 많아 AF를 매우 빨리 돌린다. 고유명사 표기는 [glossary.md](../glossary.md)를 따른다.

출처 시점: 의협의 사냥꾼 라클레어 문서(2025-07)는 세리에스(AS)(Ver3.13.70, 2026-01) 실장 전이라 그 편성의 「セリエス」는 NS([세리에스](../characters/cerius.md))다.

## 멤버

Seesaa 세리에스(AS) 문서의 정리: 서포터는 네코코(ES)나 리나리아, 디버퍼는 의협의 사냥꾼 라클레어가 정석, 서브 어태커 후보는 클러그혼·아나벨(ES)·세티.

| 캐릭터 | 무기 | 맡는 일 |
|---|---|---|
| [세리에스(AS)](../characters/cerius_as.md) | 활 | 메인 어태커. 鎧通·射切 모드 전환. 「射切」은 턴 시작마다 자신 외 전위 <활><창> 수만큼 쌓인다 |
| [의협의 사냥꾼 라클레어](../characters/laclair_alter.md) | 활 | 디버퍼 겸 서브 어태커. SA 후 전위로 시작하고 전위 <창><활> 4명이면 개막 極・瞬突陣 + ウェポンブレイク(찌르기) 3 |
| [네코코(ES)](../characters/necoco_es.md) | 활 | 서포터. 라클레어가 못 거는 버프를 채운다 |
| [리나리아](../characters/linaria.md) | 검 | 후위 글래스터 담당 자리에 두었다가 전위로 올려 「オーソリゼーション」으로 連携 |

| 웨네피카 | — | 보조 서포터. 적의 ZONE 파괴에 대비하고 네코코(ES)와 함께 아군을 그림자 속성화. 「カターラエヴォギア」 全属性耐性 버프, 「愛を呪いし怨鳥」 全属性耐性 디버프 |

그 밖의 후보: 은빛을 휘감은 번개술사(AS)(턴 시작 腕知 디버프, 「トリプレットバリア」로 상태 이상·날려 보내기 대책), 세티(재밍 회피, 「ホールドアップ」로 AF 게이지), 빙무의 가희 유키노(歌唱 지원·庇立て로 迎撃 유도, 라클레어를 斥候 칸에 두면 턴 종료 배리어 관통 추격), 유키노(AS)(速度 100% 디버프·全属性耐性 버프로 완봉 판), 보라 의상의 창술사(후위에 두었다가 필요한 턴에 올려 アナザーセンス만 쓰는 칸), 히스메나(개막 極・瞬突陣 + ウェポンブレイク → SA 어빌리티의 VC 발동으로 0턴 킬, 대신 속도를 희생), 알마(NS)(총·활 퍼스낼리티라 글래스터 담당이나 어태커).

라클레어는 腕力·속성 공격·치명타 확률 버프를 스스로 못 건다. 그래서 라클레어 문서는 서포터 2 + 어태커 2를 이상으로 보고, 두 번째 서포터로 네코코(ES)(가장 쉬움)나 아나벨(ES)(腕速 버프만)을 넣는다.

## 편성

### 순수 찌르기 파티 (세리에스(AS) 문서, 2026-01)

| 전위 | 후위 |
|---|---|
| 네코코(ES) — 서포터 | 라클레어 — 글래스터 담당 |
| 세리에스(AS) — 어태커 | 꽃피우는 공주 츠키하 — 글래스터 담당 |
| 의협의 사냥꾼 라클레어 — 디버퍼 | |
| 클러그혼 — 어태커 | |

받기는 라클레어의 디버프와 클러그혼의 SB 守護로 하고 나머지는 모두 공격에 쓴다. 글래스터 담당 한 명을 리나리아로 바꾸면 전위로 올렸을 때 連携를 붙인다.

### 라클레어 + 네코코(ES) (라클레어 문서, 2025-07)

| 전위 | 후위 |
|---|---|
| 네코코(ES) — 서포터 | 알마 — 글래스터 담당 |
| 의협의 사냥꾼 라클레어 — 서브 어태커 | 보라 의상의 창술사 — アナザーセンス 칸 |
| 세리에스 (NS) — 어태커 | |
| 웨네피카 — 서포터 | |

메인 화력은 세리에스(NS)의 「一斉射撃」. 웨네피카가 SB 「イユンクス」로 極・刻陰陣을 편 뒤에는 네코코(ES)의 「猫又巫女神楽」로 아군 전체에 変幻自在(陰)를 건다. 라클레어의 효과는 瞬突陣과 관계없이 늘 풀 성능이라, 글래스터 담당에게 激震 글래스터와 黒陰 글래스터를 함께 들린다.

### 라클레어 + 아나벨(ES) (같은 문서)

위 편성의 웨네피카 자리를 아나벨(ES)로 바꾼 공격형. 네코코(ES)의 EX 필살기가 쉬워져 「スーパー☆ねここ様」를 자주 켜고, 세리에스의 재행동과 합쳐 AF 게이지를 매우 쉽게 회수한다. 아나벨(ES)을 천으로 쓰면 나머지 두 명이 천, 명이면 명으로 고정된다.

## 약점

- 창·활 전용이다. 「射切」 누적, 라클레어의 디버프 강화·재실행, 「ハンターズ・ハイ」가 모두 전위 <창><활> 수에 달려 있다.
- 찌르기 위주의 적에게는 瞬突陣이 적의 피해도 키운다.
