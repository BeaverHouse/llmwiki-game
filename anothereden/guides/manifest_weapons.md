# 현현 무기와 結実 무기

현현(顕現)은 대상 동료의 전용 무기를 얻는 전투 콘텐츠다. 무기를 얻고 키우면 그 동료의 ☆5 스킬이 강해져, 평가가 현현 전후·진현현 후로 갈린다. 콘텐츠명·아이템명은 일본어로 둔다.

## 세 단계

| 단계 | 콘텐츠 | 내용 |
|---|---|---|
| 현현 | 「武器との巡り逢い」 | 보스를 격파해 전용 무기를 얻는다. 장착하고 키워야 하며, 무기 Lv6에서 ☆5 스킬 강화가 붙고 성장할수록 커진다 |
| 진현현 | 「真・武器との巡り逢い」 | 무기 Lv10에서 鬼の爺에게 다시 말을 걸면 강화된 보스와 싸운다. 이기면 무기 기본 성능과 ☆5 스킬 2종이 크게 강화되고 소비 MP가 준다 |
| 結実 | 「結実せし武器との交わり」 | 「武器との巡り逢い」를 대체한다. 시작하는 시점에 무기를 얻고 그때 스킬 강화가 적용된다(장착·보스 격파 불필요). 「(真)武器との巡り逢い」 달성 여부와 상관없다 |

## 시작 조건

- 장소: 次元の狭間 顕現の間(중앙 위쪽).
- 메인 스토리 1부 클리어, 대상 동료(☆5)를 편성하고 그 동료의 캐릭터 퀘스트 3화 클리어. AS와 ☆4로 3화를 클리어했으면 NS ☆5가 없어도 된다.
- 현현 전투는 컨티뉴 불가, 기간 한정 아님.

## 結実 무기

- 고유 어빌리티: 성장 Lv10에서 장착자의 기본 능력치가 오른다. 「極彩の虹石」으로 Lv11이 되면 동료마다 다른 어빌리티가 붙는다(예: 라클레어는 Lv10 腕力+30·速度+30, Lv11 九死一生).
- 커스터마이즈 어빌리티: 슬롯에 「才珠」를 끼운다. 효과는 얻을 때 색마다 정해진 후보에서 무작위로 정해진다.
- 기존 현현 무기는 結実 대상이 되면 성장 Lv를 이어받아 변환된다(Lv10 이상 → Lv10 結実 무기). 장착 레벨 제한은 Lv60에서 Lv1로 바뀐다.

| 才珠 | 주요 후보 |
|---|---|
| 紅輝 | 全属性攻撃+50/30/20%, クリティカル率·魔法クリティカル率+150/100/80%, MP+150/100/80, 常にMP治癒(30/20), HP最大時ダメージ+40%, HP50%以下時ダメージ+50%, 無属性攻撃+50%, 九死一生, ペイン時·毒時強化+30%, コンボ倍率強化 |
| 蒼輝 | 全属性攻撃+50/30/20%, 速度+50/40/30, HP+2000/1500/1000, クリティカル率+150/100/80%, 攻撃時腕力·知性25%DOWN, 攻撃時速度50%DOWN, 腕速知バフ効果量15%UP, 奇襲戦法 |
| 橙輝 | 全属性攻撃+50/30/20%, 速度·HP·MP, MP消費量-30/20/15%, 攻撃時物理·魔法·全属性耐性DOWN, 腕速知デバフ効果量10%UP, 奇襲戦法 |
| 薄紅·薄蒼·薄黄·薄鉛 | 디버프 내성 +75~100%, 腕力·知性 +10~20, 全属性攻撃+10%, 상태 이상 내성 등 |
| ランダム | 모든 才珠 중 무작위 |

## 아이템 입수

- 才珠는 結実 전투 승리 시 레어 보상으로 나온다.
- 「顕現せし闘気」(結実 전투 첫 클리어, 난이도 챌린지의 誓約 보상)를 顕現の間의 노포우족에게 교환한다. 誓約은 매주 화요일 12시에 갱신되는 주 1회 달성이고, 모든 동료의 현현 전투에서 공유된다.

| 교환품 (제한) | 필요 수량 |
|---|---|
| 紅輝·蒼輝·橙輝の才珠 (각 10) | 闘気 ×600 |
| 薄紅·薄蒼·薄黄·薄鉛の才珠 (각 10) | 闘気 ×300 |
| ランダム才珠 (10) | 闘気 ×500 |
| 極彩の虹石 (3) | 闘気 ×5,000 |
| 復元の才珠 (1) | 闘気 ×2,000 |
| 上級·中級·下級武具秘伝巻子 (10·30·50) | 1,000,000 / 500,000 / 100,000 Git |

才珠와 極彩の虹石의 제한은 매월 1일 0:00, 復元の才珠와 巻子는 매주 화요일 12:00에 초기화된다.

## 무기 키우기

- 현현 무기를 아무 동료(Lv60 이상)에게 장착해 적을 쓰러뜨리거나 「武具秘伝巻子」를 쓴다. 배지·장비의 획득 경험치 증가는 적용되지 않는다.
- 필요 경험치: Lv2 500,000 / Lv3 750,000 / Lv4 1,150,000 / Lv5 약 1,680,000 / Lv6 약 2,400,000 / Lv7 약 3,800,000 / Lv8 약 5,690,000 / Lv9 약 8,500,000 / Lv10 약 12,800,000.

- 結実 (22명, 스타일 표기 없음): 히스메나, 이스카, 세티, 뮬루스, 렌리, 마리엘, 유나, 로키드, 아나벨, 로제타, 틸릴, 클로드, 애니, 호오즈키, 빅트, 펠미나, 미스트레아, 듀이, 가리유, 이벨라, 라디카, 라클레어.
- 현현 「武器との巡り逢い」: 수제트, 마이티, 시온, 투바, 아자미, 나기, 유인 등과 AS 다수(57칸, 結実 대상 포함).
- 진현현: 수제트, 마이티, 시온, 투바, 아자미, 가리유, 라클레어, 나기, 유인, 로키드, 뮬루스, 츠키하, 베르트랑, 메리나, 셰이네, 유나.

애니·뮬루스·클로드는 打ち直し 무기보다 結実 무기가 나을 수 있다([武器打ち直し](weapon_reforging.md)).
