# 結実ラクレア

현현 「結実せし武器との交わり」에서 라클레어의 結実 무기 「減龍ノ弓箭」를 걸고 싸우는 보스다. Ver3.17.50(2026-10-22)에 라클레어가 結実 대상에 들며 추가되었다. 라클레어(☆5)가 동료에 있어야 도전할 수 있다. 結実 콘텐츠 공통 규칙(才珠·闘気·주간 誓約)은 [현현 무기](../guides/manifest_weapons.md)에 있다. 고유명사 표기는 [glossary.md](../glossary.md)를 따른다.

- 減龍ノ弓箭: 무기 Lv10 腕力 +30·速度 +30, Lv11 九死一生.
- 보상 (첫 클리어 / 레어 보상):

| 난이도 | 첫 클리어 | 레어 보상 |
|---|---|---|
| STANDARD | 어빌리티 슬롯 1 개방, 顕現せし闘気 ×500 | 薄蒼·薄鉛の才珠 |
| HARD | 슬롯 2 개방, 闘気 ×1,000 | 薄蒼·薄鉛の才珠 |
| VERY HARD | 슬롯 3 개방, 闘気 ×1,500 | 薄蒼·薄鉛·蒼輝の才珠 |
| CHALLENGE | 闘気 ×2,000 | 薄蒼·薄鉛·蒼輝の才珠 |

## 기본 정보

출처는 아래 수치가 어느 난이도인지 밝히지 않는다.

| 항목 | 내용 |
|---|---|
| HP | 1,200억, ライフポイント 2 (HP가 0이 되면 하나를 써서 부활) |
| 능력치 | 腕力·知性 250, 速度 300, 耐久·精神 300, 幸運 0 |
| 내성·무효 | 내성 없음, 무효 없음 |
| 약점 | 출처 표에 글로 적혀 있지 않다. 結実 보스는 무기 주인의 속성·공격 종류에 약하다는 공통 규칙은 [현현 무기](../guides/manifest_weapons.md#結実-무기) |

공격은 물 속성·무속성 찌르기와 고정 피해다. 깰 수 없는 속성·공격 종류는 없다.

### 행동 패턴

4행동 주기를 돈다. 두 번째 부활 뒤에는 1번째가 「竜鱗神楽」 2회로 바뀌고 3번째에 「エピックレイン」이 붙는다.

| 순서 | 행동 | 효과 |
|---|---|---|
| 개막 | アナザーフォースゲージを枯渇 / 「射抜かれたいのはどいつだ？」 | AF 게이지 0 / 極・瞬突陣 |
| 1 | 竜鱗の矢 (2차 부활 뒤 竜鱗神楽 ×2) / AFディレイ | 적 하나 무속성 찌르기 + 物理耐性 디버프(중, 3턴) / AF 게이지 50% 감소 |
| 2 | アクアショット / ツインショット / 버프 해제 | 적 하나 물 찌르기 / 적 하나 고정 2,000 × 2 / 아군 전체 버프 해제 |
| 3 | スプラッシュアロー / ドラゴンハント (2차 부활 뒤 + エピックレイン) | 적 하나 물 찌르기 / 적 하나 물 찌르기 3회 + 자신 腕力·速度 버프 / 아군 전체 물 찌르기 |
| 4 | エイミングフロード / 디버프 해제 | 아군 전체 물 찌르기 + 腕力·知性 디버프(중, 1턴) / 자신 디버프 해제 |
| 1차 부활 | 「狙った獲物ははずさない！」 / 竜鏖奉射 | ZONE 해제 + 極・瞬突陣 / 아군 전체 물 찌르기 3회 |
| 2차 부활 | 「私の矢からは逃げられない！」 / 未来を紡ぐ一矢 | ZONE 해제 + 極・瞬突陣 / 아군 전체 물 찌르기 3회 + 「竜鱗の護人」 |
