# ムル・アンクン

Ver3.12.50에 추가된 숨은 보스로, 비공식 난이도표 ★11.5다([숨은 보스 난이도](../guides/superbosses.md)). 옛 보스 ローテ・リベレ와의 전투를 지금 사양으로 강화해 되살린 상대이고, 세 ムル 중 첫 번째다. 강화판은 [ムル 3파티전](muru_three_parties.md)에 다시 나온다. 영문 명칭은 확인하지 못했다. 표기는 [glossary.md](../glossary.md)를 따른다.

- 출현: 外伝 「螺旋の記憶と原初の旋律 魔獣の章」 제3화 클리어 → シュクヴァリエ 부흥 이벤트를 모두 마치고 「ルベルノクスの星珠」 → 서브 퀘스트 「遺跡に眠る厄災」에서 オットー에게 「女王即位の日の記録」 → 星天儀에서 그것을 쓰면 アストラ遺跡 2층 북동(星見の間 오른쪽) 문이 열린다. 들어가 바로 있는 작은 방의 문을 조사하면 전투. **재전 가능**. 문이 안 열리면 완료하지 못한 단계가 남은 것이다(댓글 2025-09).
- 보상: 「絶望の腕輪・真」(길드너 전용 장비).

## 기본 정보

| 항목 | 내용 |
|---|---|
| 구성 | 第1形態 → 第2形態 → 最終形態. 「ライフポイント」 2개로 HP 0마다 부활 |
| HP | 57,224,168,353(약 572.2억) × 3 형태, 스토퍼는 남은 HP 1% |
| 속성 | 약점 불·그림자. 바람·번개 **무효**(표가 아이콘이라 본문 해설에서 옮김) |
| 공격 종류 | 「嵐纏」 物理·魔法 내성 UP(中/50%/영구) |
| 능력치 | 腕力 320, 知性 660, 速度 180, 耐久 210, 精神 400, 幸運 0 |
| 공격 | 모두 바람 속성 마법. 경과 턴은 형태가 바뀌어도 이어서 센다 |
