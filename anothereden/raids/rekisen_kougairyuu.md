# 歴戦の甲鎧竜

Ver3.16.50에 추가된 숨은 보스로, 비공식 난이도표 ★11.8이다([숨은 보스 난이도](../guides/superbosses.md)). 그 표에서 가장 최근 버전의 ★11.8 이상 보스다. 영문 명칭은 확인하지 못했다. 표기는 [glossary.md](../glossary.md)를 따른다.

- 출현: 외사 「望郷の魂と逆星の旅人」 제3화 「幻霊の剣と褪色の拳」 클리어 → 술집에서 서브 퀘스트 → 숨은 보스 「暴襲のレクサ・狂堅のウルサ」(★11.1) 격파. 첫 격파 때만 연전으로 이어지고, 리트라이하면 歴戦の甲鎧竜전부터 시작한다. **재전 불가**.
- 보상: HP2500 배지.

## 기본 정보

| 항목 | 내용 |
|---|---|
| HP | 750억. 표기상 스토퍼 없음, 실제로는 「超生命力」이 0이 될 때까지 남은 HP 0.1% 스토퍼가 유지된다 |
| 형태 | 「超生命力」 누적으로 나뉜다. 제1형태 40~21, 제2형태 20~1, 최종 형태 0 |
| 공격 종류 | 약점 타격. 타격 이외 공격을 받으면 「アングリー・ヘイト」 |
| 능력치 | 腕力·知性 520, 速度 320, 耐久 500, 精神 700, 幸運 0 |
| 전투 시작 시 | 아군 전체 현재 HP 90% 고정 피해 |
