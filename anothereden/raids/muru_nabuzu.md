# ムル・ナブズ

Ver3.14.0에 추가된 숨은 보스로, 비공식 난이도표 ★11.6이다([숨은 보스 난이도](../guides/superbosses.md)). 세 ムル 중 세 번째이고, [ムル 3파티전](muru_three_parties.md)에도 같은 능력치로 나온다. 영문 명칭은 확인하지 못했다. 표기는 [glossary.md](../glossary.md)를 따른다.

- 출현: [ムル・アンクン](muru_ankun.md)·[ムル・キカ](muru_kika.md) 격파 → 外伝 「螺旋の記憶と原初の旋律 亜人の章 幸福主義」 제3화 클리어 → 現代 シュクヴァリエ에서 서브 퀘스트 「遺跡に眠る海の災厄」 → 宝物庫 건설 이벤트(神器 奉納 방 3곳 건설 뒤 진행, altema)로 星天図(Seesaa 「新女王即位の日の星天図」, altema 「新女王即位の日の記録」) → 星天儀 기동 뒤 アストラ遺跡 2층 남동쪽 퀘스트 아이콘. **재전 가능**, 두 번째부터는 1층 북동쪽 입구 근처에서 바로 간다.
- 보상: 글래스터 「刻唄の力<火>」. Seesaa는 AF 중이면서 歌唱 중일 때 불 속성 퍼스낼리티 동료의 1히트당 AF 게이지 증가량 +5, altema는 歌唱 효과 발동 중 AF 중 게이지 회복량 증가(中)로 적는다. 훈장 보상 クロノスの石 50개(altema).

## 기본 정보

| 항목 | 내용 |
|---|---|
| 구성 | 第1~第3形態 + 最終形態. 「ライフポイント」 3개로 HP 0마다 부활 |
| HP | 第1~第3形態 21,224,168,353(약 212.2억) × 3, 最終形態 106,120,841,765(약 1061.2억). 스토퍼는 남은 HP 1% × 3 |
| 속성 | 약점 불. 무효·흡수 없음(본문 해설 기준) |
| 공격 종류 | 약점 찌르기. 베기 내성이 있는 것으로 보인다(altema가 「墨染の軍師」로 베기 내성을 약점으로 뒤집으라고 적음. 표가 아이콘이라 확인하지 못함) |
| 상시 | 피해 50% 컷 배리어(영구), 「ダメージ軽減」(中/25%) |
| 능력치 | 腕力·知性 244, 速度 217, 耐久·精神 206, 幸運 10(형태마다 조금씩 오름) |
| 공격 | 물 속성 물리·마법을 둘 다 쓴다. 공격 빈도와 능력치는 낮다 |
