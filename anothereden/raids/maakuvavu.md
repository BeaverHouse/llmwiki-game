# マークヴァヴ

Ver3.15.50(2026-06, [하보크](../characters/havoc.md)와 같은 버전)에 추가된 숨은 보스다. 비공식 난이도표 ★11.6([숨은 보스 난이도](../guides/superbosses.md)). 모든 속성·공격 종류에 내성이 있고, 아군 공격 횟수로 방어 단계가 바뀐다. 표기는 [glossary.md](../glossary.md)를 따른다.

- 출현: 외사 제2화 「幻霊の剣と暗溟の残光」 클리어 → ヴォーロス研究所 최심부(アイ・オブ・ザ・ストーム)에서 通信記録??-04 수신 → エリアβ를 거슬러 가 エリアβ-6 수수께끼를 푼다 → 廃棄槽 최심부에서 전투. **재전 불가**.
- 수수께끼(altema): エリアα-6 오른쪽 위 장치에 「3684」 → β-5 → β-6 입구 장치에 「9614」 → 손자국 수(5·1·2·3)와 復号キーd·レールガンの弾을 모아 아래 가운데 콘솔에 「5123」. 손자국을 본 순서와 상관없이 이 숫자만 받는다. β-6 가운데에서 廃棄槽로 가 通信記録β-6-08을 해독하면 전투가 시작된다.
- 보상: 글래스터 「極・撃陣の力<打>」. 極・轟打陣 전개 시 피해 15%UP + 全属性攻撃 20%UP, 潜在錬成하면 둘 다 【P】([글래스터](../guides/grasta.md)). 가는 길 보물상자에 글래스터 「全能の力<科学者>」(altema).

## 기본 정보

| 항목 | 내용 |
|---|---|
| 구성 | 3 형태, 「ライフポイント」(최대 2)로 HP 0마다 부활 |
| HP | 2000억 × 3, 스토퍼는 남은 HP 0.1% × 2 |
| 속성·공격 종류 | 모든 속성·모든 공격 종류 **내성**(수치는 출처에 없음). 약점·무효·흡수 없음 |
| 능력치 | 腕力·知性 310, 速度 350, 耐久·精神 500, 幸運 0 |
| 적 공격 | 피해를 주는 공격은 모두 번개 찌르기. 베기 공격은 없다 |

깰 수 없는 속성·공격 종류는 없다. 내성은 弱点看破로 건너뛴다. 먹빛의 책사(NS)가 개막 AF에서 「調虎離山」을 쓰면 적이 모든 속성·공격 종류 약점이 되고, 이 반전은 영구라 쓴 뒤 후위로 내려도 된다. 이 편성은 ZONE 없이 짧게 끝내고, AF 게이지는 「ファイアラッシュ」·「ドラゴンピアース」로 채운다.

## 클리어 파티
