# シュペトニク

Ver3.8.15(2024-07)에 추가된 숨은 보스다. 3부 後編 108장의 ライカ集め 이벤트에서 수리 부품(修理パーツ)을 5개 모은 뒤 プラニエ島 맵 왼쪽 「！」로 싸운다. 재전 불가다. 쓰러뜨리면 [カプトニク](kaputoniku.md)와 싸울 수 있다. 비공식 숨은 보스 난이도표 ★11.3.

- 보상: クロノスの石 ×50.
- 난이도표 메모: 높은 HP·화력, 상태 이상, 毒ペ 무효, 버프·디버프 수 관리, 동반 몬스터 격파 필수, 베기 말고는 받는 피해 증가, HP 고정 피해, 버프·디버프 리셋.

## 기본 정보

| 항목 | 내용 |
|---|---|
| 구성 | 본체 + 左心核·右心核 |
| HP | 본체 9.80억 × 3 게이지(979,779,269, 스토퍼는 남은 HP 0.1% × 2), 左心核·右心核 각 8.90억 × 3(890,708,426) |
| 속성 | 본체는 약점·내성·흡수 없음 |
| 공격 종류 | 본체는 베기·찌르기·타격·마법 **무효**. 빛나는 쪽 팔을 부수면 풀린다 |
| 본체 능력치 | 힘·지능 376, 속도 252, 내구·정신 242 |

左心核·右心核의 약점·내성은 출처 표가 그림이라 확인하지 못했다. 본체 공격 대부분이 불 속성이다.

### ライカマジック

이 전투와 カプトニク전에서는 강화된 ライカマジック를 쓴다. 쓰려면 プラニエ島에서 얻는 スピリット 방어구가 있어야 한다([방어구](../guides/armor.md)).

| 마법 | 방어구 | 쓰는 동료 | 강화 후 효과 |
|---|---|---|---|
| 紅 | スピリットリング | 반지 장비(지팡이·도·활) | 적 전체 모든 속성 저항 75% DOWN(3턴) + 아군 전체 全属性攻撃 75% UP(3회 행동) + 물리·마법 치명타 피해 50% UP(3턴) |
| 蒼 | スピリットネックレス | 목걸이 장비(도끼·권갑) | 선제로 적·아군 전체 버프·디버프 해제 + 적 전체 힘·지능·속도 50% DOWN(3턴) + 아군 전체 모든 속성 저항 50% UP(3턴) |
| 金 | スピリットバングル | 팔찌 장비(검·창·망치) | 아군 전체 회복 + 상태 이상 회복 + 상태 이상 무효(3회). 회복 배율은 Seesaa가 특대 4배, altema가 특대 3배다 |

- 「蒼」은 오라 발동을 막고 스토퍼의 저항 디버프를 지운다. 받을 턴에 「蒼」, 몰아칠 턴에 「紅」을 쓴다.
- 편성은 속성을 맞추면서 반지·목걸이·팔찌 동료를 한 명씩 넣는다.
- 도끼 서포터로 네코코(AS)가 좋다. 속성 ZONE만 펴면 어느 속성 파티에도 들어간다. 스토퍼를 깬 다음 턴에 「蒼」, AF 때 「霊恵虹変怪」.
