# 셴화

일본 서버 Ver3.6.50(2024-04-12)에 추가된 ☆5 캐릭터다. 夢見 캐릭터 가운데 처음 나온 無 속성 마법 어태커로, 杖 파티(魔 파티)의 화력 핵이다. 無 속성이라 적의 속성 내성 버프에 걸리지 않고 魔法耐性만 영향을 받는다. Seesaa Wiki 「環境キャラ・装備まとめ」(2025-07)의 최상위 등급이며, 사이트 데이터의 tier는 op이다. Seesaa Wiki는 글로벌 서버 표기를 "仙華"라고 적었다. 고유명사 표기는 [glossary.md](../glossary.md)를 따른다.

이 문서는 星導覚醒(SA)까지 포함한 NS를 중심으로 쓰고, 2026-06 추가된 AS는 아래 별도 절에 적는다.

## 기본 정보 (NS)

| 항목 | 내용 |
|---|---|
| 등급 | ☆4~☆5 (星導覚醒 가능) |
| 실장 | Ver3.6.50 (2024-04-12, 일본 서버) |
| 속성·무기 | 無·杖 (冥 캐릭터) |
| 역할 | 어태커, 서포터 |
| 입수 | 夢見 (가챠) |
| 클래스 체인지 서적 | 「太乙真人の書」 ×1 (工業都市廃墟(VH)에서 드롭) |
| 클래스 증표 グラスタ | 「太乙真人の証」 知性 +5 / MP +25 |
| 세트 버디·顕現 | Seesaa Wiki에 기재 없음 |

- 전위로 턴 시작 시 모드 체인지 「集合知」.
- 「集合知」: 전투 시작 시 아군 전위의 知性 평균에 따라 자신의 魔力 상승(최대 300) + 魔法クリティカル率 100%UP. AF 중에 습득 스킬을 쓰면 풀리고, 다음 턴 시작에 돌아온다.
- VC: 幻魔陣 전개 + 적 전체 魔法耐性 DOWN(Lv3 35%, 증표 시 50%).
- 星導覚醒 패시브: 전위로 전투 시작 시 전위 <杖> 캐릭터에게 精神統一 + 杖 장비자 피해 50%UP(3턴). SB 시 冥の力が多い時 아군 전체 魔法クリティカル 피해 30%UP. 전위에 <KMS社> 아군 2명 이상이면 冥の力 축적량 증가.

「ブレイクダウン」·「ハッキング」은 적과 아군 양쪽에 걸리므로, 아군 쪽 디버프는 마리엘의 「無垢の揺り籠」(デバフリバーサル) 등으로 지운다.

## 왜 쓰는가

- **압도적 화력**: 「ホライゾン」은 知性 버프의 효과가 사실상 2배로 들어간다. Seesaa Wiki는 3부 후편 이후 적 인플레이션 속에서도 화력이 압도적이라고 평했다.
- **속성을 가리지 않는다**: 無 속성 마법이라 적의 속성 내성이 무관하다. SB 「テッセラクト」의 弱点看破<魔>는 어떤 속성의 적에게도 약점을 만들고, バフリバーサル은 적의 버프를 디버프로 뒤집는다. 그래서 형태마다 흡수 속성이 바뀌는 [アン・キ・ディグマ](../raids/an_ki_digma.md)에서도 속성 무관 공격 축으로 꼽혔다.
- **조건이 쉽다**: 전위를 杖 캐릭터로만 세우면 성능이 다 나온다. 魔 ZONE(幻魔陣) 아래에서는 마법 이외 공격의 피해가 0.7배가 되고 AF 게이지도 잘 안 차므로 杖으로 통일하는 것이 기본이다.
- **주의점**: 장비의 全属性攻撃 UP은 無 속성에 얹히지 않는다(全能 グラスタ나 亜空 무기는 의미가 없다). 스킬로 거는 全属性攻撃 버프는 얹힌다. ZONE은 적에게도 효과가 있어 마법 위주의 적에게는 받는 피해가 늘어난다.

스킬 구성과 순서: 「トリニティ」「ホライゾン」「リンク」 기본, 冥 80 이상이면 「ブレイクダウン」 추가. 「リンク」 → 「トリニティ」 → 「ホライゾン」 순으로 쓴다. Seesaa Wiki는 冥 120 이상으로 올려 배지 2칸을 확보하라고 권하며, SA 우선도가 높다고 평했다.

| 전위 | 후위 |
|---|---|

| 로제타 — 힐러 (冥 杖 캐릭터면 누구든 대체 가능) | |

개막부터 폼(AS)과 셴화가 풀 성능을 내도록 하고, SB를 끼워 極・幻魔陣 턴을 늘린다. 디버프를 맡기려면 쿠치나와와 [유나](yuna.md)를 함께 넣는 편성도 있고, [마리엘](mariel.md)을 歌唱 담당으로 넣는 편성도 있다.

### 陰 파티

전위 애니 · 웨네피카 · 셴화 · 투바(ES), 후위 グラスタ 담당 2명. 개막에 웨네피카의 효과로 陰 ZONE이 펼쳐지고, 애니의 「ワルプルギスの闇夜」로 셴화의 스킬이 陰 속성이 된다. 야쿠모 자리에 셴화를 넣는 형태다.

다른 궁합: 플람라피스(AS) (精神統一 담당), 백자의 마인 밍화, 이프(AS) (知性 버프).

- 무기: 冥鬼の錫杖(打ち直し) (無 속성 공격 +50%, エルピス 무기가 없을 때의 첫 후보), アセト・ヴィータ(打ち直し) (서포트 운용).
- 구체적인 배지 추천은 Seesaa Wiki에 없다.

## 셴화(AS)

일본 서버 Ver3.15.60(2026-06-18)에 추가된 ☆5 서포터·어태커다. NS가 순수 어태커라면 AS는 적의 특성을 바꾸는 서포터다. 통상 공격 변화 「リバースホール」로 あべこべ(3턴)를 걸고, 「インテグラル」로 적 전체 全属性耐性 50%DOWN(적에게 약점이 있으면 100%)과 함께 자신과 오른쪽 칸 杖 캐릭터에게 変幻自在·속성 공격 100%UP·下克上을 건다. 星導 스킬 「ディメンションゼロ」는 적에게 バフリバーサル, 자신에게 デバフリバーサル을 걸며 SB 시 3턴 지속에 최대 10500%다. 「集合知」는 AS에서는 쓰지 않는다. 야쿠모(AS), 에바와의 궁합이 강조된다. altema 검색 결과 요약상 점수는 NS 99점, AS 98점이다.
