# 틸릴(ES)

일본 서버 Ver3.5.10(2023-12-31)에 추가된 틸릴의 엑스트라 스타일(ES)이다. 결정 속성 검 캐릭터로, 명 아군에게 거는 강력한 버프와 輝晶陣 전개를 맡는 서포터이면서, 성도각성(SA) 후에는 「剣持つ救世主」 상태에서 고위력 전체 공격을 쏘는 어태커도 된다. Seesaa Wiki 「環境キャラ・装備まとめ」(2025-07)의 최상위 등급이며, 사이트 데이터의 tier도 super_op이다. 글로벌 서버 실장 여부는 확인하지 못했다. 고유명사 표기는 [glossary.md](../glossary.md)를 따른다.

## 기본 정보

| 항목 | 내용 |
|---|---|

| 실장 | Ver3.5.10 (2023-12-31, 일본 서버) |
| 속성·무기 | 결정·검 |
| 역할 | 서포터, 어태커 |

| 클래스 체인지 서적 | 「새크라멘트의 개전」 ×5 (각종 VH アナダン, ガルレア アナダン에서 드롭) |
| 클래스 증표 글래스터 | 「サクラメントの証」 腕力 +5 / 速度 +5 |
| 세트 버디 | 모케. 차지 스킬 「怒涛のモケ一族」로 3턴간 「剣持つ救世主」 상태가 된다 (사용 후 2턴 뒤 재사용 가능). ANOTHER ZONE 전개 중에는 차지량 +1 |

- ルナティック 시 EX 레벨 +1.
- VC: 輝晶陣 전개 + 아군 전위·후위 HP·MP 회복 (Lv3 30%, 증표 시 50%).
- 「剣持つ救世主」(모드 체인지): 소비 MP 0, 자신의 스킬 위력 1.2배.
- 성도각성 패시브: 전투 시작 시 「剣持つ救世主」 3턴. SB 시 冥の力が多い時 전개 중인 ANOTHER ZONE 지속 +3턴. 전위에 명 아군 3명 이상이면 冥の力 축적량 증가.

## 핵심 스킬

| 「心の剣」 (星導) | 0 | 적 전체 결정 斬 4연타 + 배리어 관통 (강화 후 2650% × 4). 실행 후 「剣持つ救世主」 해제, 그 상태가 아니면 불발. SB 시 명 아군에게 変幻自在<晶>(턴 종료까지) + 버디 차지 5 |

「プロミストランド」의 連撃数 증가는 원래 스킬의 위력·속성을 그대로 한 번 더 치는 것이라 단발 고위력 스킬은 사실상 2배가 되고, 버프·디버프 리셋에도 지워지지 않는다. 連携 공격에는 효과가 없고 追撃 스킬에는 있다.

「心の剣」의 위력은 Seesaa Wiki 요약문이 10500%, 스킬표가 2650% × 4 = 10600%로 적어 서로 약간 다르다.

## 왜 쓰는가

- **명 파티의 버퍼**: 「プロミストランド」 하나로 腕知速 100%, 心技一体, 精神統一, 검 캐릭터의 공격 횟수 +1을 명 아군에게 5턴 건다. 선제라서 버프 리셋 직후에도 바로 다시 깔 수 있다. 결정·명·검 어느 쪽 캐릭터와도 시너지가 있어 명 중심 파티라면 어디든 출장한다.
- **輝晶陣 담당**: 「ベネディクション」은 스킬로 輝晶陣을 펴는 첫 스킬이다. 다른 속성 파티에 출장할 때도 개막 AF를 안정시키는 데 쓴다.
- **SA 후 어태커**: 전투 시작부터 「剣持つ救世主」라 개막부터 「フォトンメサイア」로 AF·스텔라 게이지를 모으며 서포트하고, 상태가 끝날 즈음 SB 「心の剣」 → 모케의 「怒涛のモケ一族」로 다시 「剣持つ救世主」에 들어가는 순환을 돈다. 비각성 상태에서는 「怒涛のモケ一族」를 쓰기 전까지 어태커 성능이 나오지 않는다.
- **약점**: 스킬 칸이 부족하다. 초반에는 「フォトンジャッジ」 계열의 MP 부담이 크다. 단발 어태커를 지원할 때는 「トラストアポストロ」의 효과가 약하다.

스킬 구성: 비각성은 「フォトンメサイア」「プロミストランド」「ベネディクション」(명 80 이상이면 「トラストアポストロ」 추가). 각성 후에는 「フォトンメサイア」「心の剣」「プロミストランド」 고정에 「ベネディクション」과 「トラストアポストロ」 중 하나.
