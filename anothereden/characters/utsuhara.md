# 우츠하라

일본 서버 Ver3.8.20(2024-07-25)에 추가된 번개 속성 도끼 어태커 겸 탱커다. 「竜の残魂」을 쌓아 턴 종료 추격으로 적에게 「竜の爪痕」을 쌓고, 爪痕으로 스킬을 강화하는 누적 관리형 캐릭터다. 「ルナティック+」와 SA의 「転竜の護り」로 守護를 켜 강한 공격을 혼자 받을 수 있어, [번개 파티](../guides/thunder_party.md)에서는 守護 탱커나 AF 게이지 회수 담당으로 쓰인다. 고유명사 표기는 [glossary.md](../glossary.md)를 따른다.

## 기본 정보

| 항목 | 내용 |
|---|---|
| 등급 | ☆4〜☆5 (성도각성 가능) |
| 실장 | Ver3.8.20 (2024-07-25, 일본 서버) |
| 속성·무기·천명 | 번개 · 도끼 · 천 |
| 역할 | 어태커, 탱커 |
| 입수 | 夢見 |
| 클래스 체인지 서적 | 「ドラゴンリーパーの書」 ×1 (나다라 화산(VH)에서 드롭) |
| 클래스 증표 글래스터 | 「ドラゴンリーパーの証」 腕力 +5 / HP +300 |
| 특성 | 도끼, 용, 드래곤 킬러, 연옥계, 아르카디아 |

- VC: 招雷陣 전개 + 자신에게 치명타 피해 UP (Lv3 35%·1턴, 증표 시 45%·2턴).
- 패시브: 전투 시작 시 ルナティック(3턴). ルナティック 상태로 턴을 시작하면 자신에게 치명타 확률 100%UP(1턴). 턴 종료 시 竜の残魂을 소비해 적 전체 번개 斬(최대 3회).
- 링크 어빌리티(招雷陣 전개 중, 전위 아르카디아 캐릭터 수): 2명 이상 아군 전체 魔法耐性 20%UP, 4명이면 아군 전체 変幻自在(雷).
- SA 패시브: SB 시 天の力が多い時 적 전체 번개 내성 50%DOWN(턴 종료까지). 전위 <용> 2명 이상이면 天の力 축적량 증가(최대 +5). 전위로 전투 시작 시 竜の残魂 2 + 転竜の護り 1 누적.
- 누적 「竜の残魂」(최대 3): 턴 종료 시 1 소비해 적 전체 번개 斬(640%, 4배) + 竜の爪痕 1. 残魂이 없어질 때까지 반복(최대 3회).
- 누적 「竜の爪痕」(최대 10, 적에게 쌓임): 爪痕이 있는 적에게 일부 스킬 추가 효과.
- 누적 「転竜の護り」(최대 1): SB로 「雷咲・青蓮華」를 쓰면 턴 종료까지 자신에게 守護 + 1 소비.

## 왜 쓰는가

- **守護 탱커**: 守護 중에는 아군이 받는 공격을 모두 대신 받고 전투 불능이 되지 않는다. 「ルナティック+」는 "강한 공격을 한 번 받고 싶을 때"의 비장의 패다. SA면 개막 転竜の護り로 「ルナティック+」와 합쳐 守護 패가 2장이 된다.
- **守護 + 迎撃**: 「顕加の纏」의 迎撃을 켠 채 守護로 전체 공격을 받으면 한 번에 迎撃이 4회 나간다. AF 중에 「顕加の纏」을 깔아 두고 받고 싶은 턴에 守護를 켠다. 迎撃으로 残魂이 쉽게 3까지 차서 턴 종료 추격 손 수도 는다(스코어 어택). 守護·迎撃의 일반 규칙은 [상태 효과](../guides/status_effects.md) 참고.
- **AF 게이지 회수**: 턴 종료 추격(최대 3회)으로 AF 게이지를 15%(+30) 번다. 招雷陣 아래 비AF에서 게이지가 잘 안 차는 번개 파티에 도움이 된다([이즈나](izuna.md) 문서).
- **상시 치명타**: 전투 시작 ルナティック + 턴 시작 치명타 100%UP 덕분에 치명타 확정이 아닌 강한 무기(ムジマ 장비 등)도 쓸 수 있다. 버디 건스가 있으면 ルナティック 상태를 쉽게 이어 사실상 영구 치명타 버프가 된다.

## 운용

- 기본 스킬: 「廻転竜雷・阿頼耶」「蒼雷纏現・優鉢羅」「顕加の纏」.
- 순서: 「廻転竜雷・阿頼耶」 → 턴 종료 추격 → 「蒼雷纏現・優鉢羅」. 단일 적이면 「蒼雷纏現・優鉢羅」 뒤에는 「廻転竜雷・阿頼耶」 연타. 「廻転竜雷・阿頼耶」는 招雷陣 + 단일 상대에서 유리하고, 「蒼雷纏現・優鉢羅」는 적이 여럿일 때 유리하다(단일이면 心技一体 부여용 보조 스킬에 가깝다).
- 残魂 수급: 주로 「廻転竜雷・阿頼耶」(+3). 약점 「無相の雷光」(+2), 迎撃 발동 「顕加の纏」(+1)로도 쌓이지만, 최대로 하려면 「無相の雷光」 2회, 「顕加の纏」 3회가 필요하다.
- 爪痕은 턴 종료 추격으로만 쌓여 1턴에 최대 3. 「雷咲・青蓮華」 3회 행동에는 爪痕 9 이상이 필요하므로, 2턴마다 「雷咲・青蓮華」를 쓸지 9까지 기다려 최대 위력으로 쓸지 고른다.
- SB 「雷咲・青蓮華」는 **2번에 1번만 守護**가 된다(転竜の護り가 있을 때 소비해 守護, 없을 때는 쌓기만). 守護가 필요한 턴에 맞춰 SB를 쓴다.
- 招雷陣형 아르카디아 파티에서 류제와 「ライリス」는 招雷陣에 맞춰 스킬이 바뀌지 않아 시너지가 작다. 어태커는 알도와 우츠하라 중심으로 짠다.

## 편성 예시

### 알도 + 오보로 축 확장판

| 전위 | 후위 |
|---|---|
| 베레토 — 서포터 | 츠키하 — 글래스터 담당 |
| 우츠하라 — 탱커 | 류제 — 글래스터 담당 |
| [오보로](oboro.md) — 어태커 | |
| 알도 — 서브 어태커 | |

AF 게이지 회수와 極・招雷陣은 건스로 하면 안정된다. 알도·우츠하라 두 쪽 화력을 함께 올리려면 류제를 후위에. 한쪽에 몰려면 알도는 클로드(ES), 우츠하라는 이루루 등이 글래스터 담당 후보.

### 순수 번개 파티

| 전위 | 후위 |
|---|---|
| 베레토 — 서포터 | 츠키하 — 글래스터 담당 |
| 오를레아(NS) — 서포터 | 이루루 — 글래스터 담당 |
| [오보로](oboro.md) — 어태커 | |
| 우츠하라 — 서브 어태커 | |

오를레아는 「ルナティック+」를 1회 늘리려고 일부러 NS를 쓴다. 極・招雷陣을 거의 늘 펼 수 있어 覚醒·撃陣 글래스터로 효율 좋게 피해를 늘린다. [베레토(AS)](velette_as.md) 문서의 현재 순수 번개 편성(우츠하라 守護)은 [번개 파티](../guides/thunder_party.md) 참고.

### 번개형 아르카디아 파티

| 전위 | 후위 |
|---|---|
| 멜피피아 — 서포터 | 사잔카 — 글래스터 담당 |
| 우츠하라 — 탱커 | 류제 — 글래스터 담당 |
| 세리에스 — 어태커 | |
| 알도 — 서브 어태커 | |

전위를 아르카디아로 채워 번개 파티로 쓴다(링크 어빌리티 4명 = 変幻自在(雷)). 어태커는 알도·세리에스·우츠하라 세 축. 적의 내성에 대처하려면 세리에스 대신 사잔카. 유일하고 가장 큰 약점은 招雷陣 유지가 어렵다는 것으로, 장기전에는 그다지 맞지 않아 적의 공격은 守護로 받으며 압도적 화력으로 밀어붙인다.

이 위키의 다른 문서에 실린 편성: [마리엘](mariel.md)의 斬突 편성(우츠하라 追撃), [歴戦の甲鎧竜](../raids/rekisen_kougairyuu.md)의 메리나 축.

## 궁합

- [오보로](oboro.md): SA면 AF 후 弱点看破(雷)와 시너지가 매우 크다. 최대 피해 타이밍이 AF 다음 턴으로 분명해져 누적 관리도 쉬워진다.
- 알도: 아르카디아 파티, 알도 + 오보로 축 모두. 용·아르카디아 두 특성이 일치한다.
- 오를레아: 어빌리티로 「ルナティック+」 사용 횟수가 1회 늘어 守護 횟수도 는다. 다만 Ver3.8.50 시점에 횟수가 늘지 않는 버그가 있었다(댓글 2024-08-22에도 미수정).
- 멜피피아: 腕知速 버프·속성 내성 버프, 「未来予知・安寧」의 HP 버프로 「廻転竜雷・阿頼耶」 シールド 강화.
- 사잔카: 멜피피아보다 공격 쪽. 아르카디아 파티에 부족한 속성 내성 디버프.
- 류제: 용·드래곤 킬러·아르카디아 세 특성을 혼자 맞춘다.
- 베레토: 순수 번개의 만능 서포터. 건스와 함께면 ルナティック을 거의 영구히 붙인다.

## 추천 장비

- 글래스터: 狙い撃つ錬成 (迎撃·추격 화력을 무조건 올린다), 共鳴の力：天錬成 (아르카디아·번개 파티 모두 천 캐릭터가 많다).
- 무기·방어구: ムジマ・アックス (치명타는 어빌리티로 메운다), 竜纏の首飾り (MP가 많지 않아 MP를 올리면 안정되고 心技一体도 커진다).
