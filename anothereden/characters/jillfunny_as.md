# 질퍼니(AS)

일본 서버 Ver3.17.0(2026-09-14)에 추가된 질퍼니의 어나더 스타일(AS)이다. スタイル 이름은 「ルブラディウス」. 輝晶陣 아래에서는 고위력 4연타를 쏟아붓는 어태커, 水天陣 아래에서는 クリティカルガード와 迎撃으로 받아치는 탱커가 되는, 편성에 따라 역할이 바뀌는 캐릭터다. Seesaa Wiki는 실장 소개에서 "환경 최상위급이 보장된 캐릭터"라고 평했다. 글로벌 서버 실장 여부는 확인하지 못했다. 고유명사 표기는 [glossary.md](../glossary.md)를 따르며, 한국어 표기가 확인되지 않은 스킬명·용어는 일본어 그대로 적는다.

## 기본 정보

| 항목 | 내용 |
|---|---|
| 등급 | ☆5 (星導覚醒 가능) |
| 실장 | Ver3.17.0 (2026-09-14, 일본 서버) |
| 속성 | 水 (輝晶陣 전개 시 주력 공격이 晶으로 바뀜) |
| 무기 | 剣 |
| 역할 | 어태커, 탱커 |
| 입수 | 夢見 (가챠) |
| 클래스 체인지 서적 | 「ルブラディウスの異節」 ×5 (グリーン・キー 2장 소비 アナダン, レッド・キー 소비 アナダン에서 드롭) |
| 클래스 증표 グラスタ | 「ルブラディウスの証」 腕力 +5 / 速度 +5 |
| 세트 버디 | 피이 (ぴーたん). NS·AS 어느 쪽이든 효과 있음 |

패시브로 火 속성 내성 +20%, 전 상태 이상 내성 +20%, ルナティック<心眼>, ZONE 어빌리티 「赫晶」을 가진다. 전투 시작 시 전위에 <晶> 퍼스낼리티 아군이 3명 이상이면 極・輝晶陣을 펴고, 메인이나 서브에 피이가 있으면 AF 게이지가 100%가 되고 「クレッセンティア」를 자동 실행한다.

## 핵심 스킬

| 스킬 | MP | 효과 요약 |
|---|---|---|
| 「インテンド」 (☆4) | 35 | 선제로 水天陣 전개 + 자신에게 腕力·知性·速度 100%UP·精神統一. 水天陣·輝晶陣 전개 중이면 버프가 5턴으로 늘고 ZONE 覚醒과 心技一体가 붙는다. 전위에 <晶> 3명 이상이면 펴는 ZONE이 輝晶陣으로 바뀐다 |
| 「インキーデレ」 (☆5 AS) | 110 | 단일 水 斬 4연타 (200%). 자신에게 「ソムニウム」 1 누적, 아군 전체 クリティカル率·魔法クリティカル率 100%UP(5회 행동)·MP 10% 회복. 輝晶陣이면 晶 속성으로 바뀌고 위력 30배(6000%), AF 콤보 배율 증가량 5배, エレメンタルブレイク(晶) 3 누적. 水天陣이면 「ソムニウム」 누적 2배, エレメンタルブレイク(水) 3 누적 |
| 「クレッセンティア」 (☆5 AS) | 68 | 자신에게 MP 최대치 70%UP, クリティカルダメージ 50%UP, 全属性攻撃 100%UP. 輝晶陣이면 ルナティック<心眼>, 水天陣이면 クリティカルガード + 迎撃(水 斬 2000%, 약점 시 4000%, 맞은 적에게 腕力·知性 DOWN 누적) |
| 「クルオルエンシス」 (星導) | 105 | 단일 水 斬 4연타. 아군 전체에 多段強化·全武器種 피해 50%UP·MP消費攻撃(피해 100%UP / 소비 MP 100%UP), 적 전체에 내성 무시 挑発. SB 시 위력 30배 후 「インキーデレ」를 3회 연속 실행 |

「ソムニウム」은 누적 1마다 MP 최대치 +50, 速度 +10, 全属性耐性 +1% (최대 30누적)이며, 星導覚醒 후에는 턴 시작 시 누적 × 50만큼 MP를 회복한다.

## 왜 쓰는가

- **晶 파티의 화력 핵**: 輝晶陣 아래에서 6000% 4연타 「インキーデレ」를 AF 중 연타하면서 아군 전체 치명타 확률까지 올린다. AF 조작은 「インテンド」 → 「クレッセンティア」 → 「インキーデレ」 연타로 끝난다.
- **水 파티의 탱커**: 水天陣 「クレッセンティア」의 クリティカルガード와 2000%(약점 4000%) 迎撃으로 받으면서 때린다. MPガード로 MP가 줄어도 「ソムニウム」과 MP 회복으로 버틴다.
- **개막 AF**: 피이를 버디로 두면 전투 시작 시 AF 게이지 100%. Seesaa Wiki는 이 점에서 뮬루스(ES)의 상위 호환으로 기능한다고 평했다. 피이(AS)를 전위 버디로 두면 오토 어택이 2회 행동이 되어 AF 게이지 회수도 빨라진다.
- **星導覚醒(SA) 후**: 「クルオルエンシス」의 MP消費攻撃이 피해 100%UP으로, 기존 フラムラピス(ES)의 50%를 크게 넘는다. SB 판은 4연타 × 4의 손 수를 낸다.

## 편성

### 晶 파티 (어태커 운용, 단기전)

| 전위 | 후위 |
|---|---|
| 틸릴(ES) — 서포터 | 루비 — グラスタ 담당 |
| 미스트레아 — 어태커 (耐性 디버프) | 노나(AS) — グラスタ 담당 |
| 알마(AS) — 탱커 | |
| 질퍼니(AS) — 어태커 | |

- 받기는 알마(AS)의 守護로 대응하고, 그 사이 버디 모케의 오토 스킬로 腕力·知性 디버프 누적을 쌓는다. 耐性 디버프는 미스트레아의 「マシアフ・ケシェト」를 개막에 연타해 3누적까지 올린다.
- 틸릴(ES)의 「プロミストランド」(연타 수 버프)와 궁합이 특히 좋다. 알마(AS)의 「カレイドスコープ」 連携까지 얹으면 SB 「クルオルエンシス」가 6연타 × 4가 된다.
- 미스트레아 자리는 빨간 외투의 화염술사(AS)로 바꿔도 되고(약점 버프·腕知 디버프 추가, 耐性 디버프는 약간 줄어듦), 더 안정적으로 가려면 니나로 바꿔 적의 ZONE 전개를 막는다.
- 날려 보내기에 약하다. 그때는 증표를 들린 노나(AS)를 전위로 올려 날려 보내기 배리어를 건다.
- 晶 파티 조건은 晶 캐릭터 3명이므로 한 자리는 자유다. 다른 속성 약점이 필요한 콘텐츠라면 그 속성 어태커를 넣는다. 다른 어태커 후보는 에바, 멜리사, 니르야.

### 水 파티 (탱커 운용, 개막 庇立て)

| 전위 | 후위 |
|---|---|
| 꿈의 음유 시인 듀나리스(AS) — 서포터 | 베르단타 — 어태커 |
| 엘실(AS) — 서포터 | 루비 — グラスタ 담당 |
| 월화의 영애 히스메나(AS) — 서브 어태커 | |
| 질퍼니(AS) — 탱커 | |

- 개막에 꿈의 음유 시인 듀나리스(AS)가 「スカリカ・バリーレ」로 질퍼니(AS)에게 庇立て를 걸고, 2턴째에 후위의 베르단타와 교대한다.
- 개막 AF로 판을 짜면서 「インキーデレ」를 연타해 「ソムニウム」을 쌓아 MPガード가 끊기지 않게 한다.
- 월화의 영애 히스메나(AS)의 「ケッテグロル」로 고배율 腕知 디버프를 건다. 엘실(AS)의 연타 수 버프는 迎撃 횟수를 두 배로 늘린다.
- 마츠리카의 오른쪽 칸에 두면 迎撃에 連携가 붙는다. 다만 AF 화력은 포기하는 迎撃 특화 운용이다.

## 추천 장비

- グラスタ: 狙い撃つ錬成 (水 파티 迎撃 운용 시 필수), 極・撃陣の力<晶> (晶 파티 후위), ZONE覚醒時強化錬成, AFコンボ倍率強化錬成.
- 千年樹の腕輪: MP를 늘려 「クレッセンティア」의 MP 버프와 MPガード 지속을 극대화한다.
- 腕力幸運バッジ: 水 파티에서 필수. クリティカルガード 경감률을 올린다.
