# Another Eden — 문서 목록

일본 서버 기준이며 글로벌도 진행이 같다. 게임 전반을 다루되 고난이도 콘텐츠(강적, 고난이도에서 쓰는 동료와 파티, 장비·글래스터 파밍)에 가장 무게를 둔다. 찾아봐야 하는 콘텐츠(정보가 흩어졌거나, 진행이 어렵거나, 선택지가 복잡하거나, 진행 상황을 파악하기 힘든 것. 예: 맵의 반짝이, 코린다 장미 퀘스트)와 시스템도 다룬다. 메인 스토리·콜라보 진행 공략은 싣지 않는다.

## 작성 기준

- 강적 문서: 도입(실장·출현·보상) → 기본 정보 → 기믹과 대처 → 클리어 파티 → 히스토리. 예시 [カプトニク](raids/kaputoniku.md).
  - 기본 정보는 내성(피해 감소, 수치), 무효(0), 흡수(회복)를 구분한다. 깰 수 없는 것은 무효·흡수뿐이고, 조건부 무효와 그것을 건너뛰는 수단(약점 간파, 상성을 뒤집는 동료)을 함께 적는다.
  - 기믹 표: 기믹, 발동, 효과, 대처, 대처 가능한 동료. 대처는 카드의 "커버하는 것"과 같은 말로 쓴다: 받기, ZONE, 아군 버프, 아군 내성, 적 디버프, 약점, 상태 이상 대책, 버프·디버프 해제, 회복·소생, 연계·배리어 관통, AF 게이지.
  - 클리어 파티: 구분(출시 당시 정석, 현재 메타, 배포, 최속, 꼼수), 시기, 근거 링크. 영상·스크린샷은 확실, 댓글·투고는 참고로 표시한다. 꼼수는 기믹의 허점이나 무한 버티기 같은 정석 밖의 방법이다.
- 동료 카드: [고난이도 동료 명단](guides/meta_characters.md)에 든 동료만. 도입(다루는 스타일) → 기본 정보 → 커버하는 것 → 쓰는 스킬 → 파티에서 → 장비·글래스터 → 히스토리. 예시 [알마(AS)](characters/alma_as.md).
  - 스킬 효과는 커버하는 것 표에 기능별로 모으고, 쓰는 스킬 표(실제로 넣는 2~4개)에는 MP와 피해만 둔다. 저절로 일어나는 메커니즘(모드 변화, 누적, ZONE 어빌리티)은 적고 패시브 내성은 적지 않는다.
  - 한국어 표기는 나무위키, 수치는 altema·영어 위키를 따른다.
  - 편성은 파티 문서에, 버디는 [버디](guides/buddies.md)에 두고 링크한다.
- 파티 문서: 속성·무기 종류마다 필수 멤버, 교체할 수 있는 자리, 되면 배포 동료 파티. 그 속성을 아무나 채운 것은 파티가 아니다. 편성에는 근거 영상이나 공략 링크를 붙인다.
- 장비·글래스터: 고난이도에서 쓰는 것만, 파밍 방법과 함께.
- 찾아봐야 하는 콘텐츠: 어디서 무엇을 어떻게 하는지, 선택지별로 무엇을 얻는지, 빠뜨리기 쉬운 것.
- 꼬리표와 스킬 사용 시점은 [AGENTS.md](../AGENTS.md) 3절을 따른다.
