## 커뮤니티 용어

| 용어     | 의미 | 출처 문서 |
| -------- | ---- | --------- |
| 빛만튀   | 빛나는 페로로 1-2마리만 때리고 퇴각하는 전략 | [perorodzilla.md](raids/perorodzilla.md) |
| 민초택틱 | 무적 자리 탱커와 아이리 EX 이속 감소로 쿠로에게 자해 데미지를 입히는 전략 | [shiro_kuro.md](raids/shiro_kuro.md) |
| 미래시   | 먼저 서비스한 일본 서버의 업데이트·시즌 기록으로 다른 서버의 앞날을 미리 보는 것. "미래시의 ○○ 총력전"은 일본 서버에서 이미 열린 시즌 | [beginner.md](guides/beginner.md) |
| 플레 / 플레컷 / 플레택틱 / 플레권 | 플래티넘(총력전·대결전 최상위 등급. 총력전은 일본 서버 20,000위, 한국 서버 12,000위 이내), 그 커트라인 점수, 플래티넘에 드는 편성, 플래티넘 순위 구간. 난이도 이름이 아님. 플레권의 권은 순위 구간이라 모집 [선택권](guides/recruitment.md)과 상관없음. "플레권 목표"는 플래티넘 안에 들겠다는 말 | [beginner.md](guides/beginner.md) |
| 골드 | 플래티넘 다음 등급. 총력전은 일본 서버 20,001~120,000위, 한국 서버 12,001~55,000위. "총력전에서 골드를 생각한다"는 이 등급을 노린다는 말이고 재화 골드가 아님 | [beginner.md](guides/beginner.md) |
| 페스 / 페스캐 | 페스 모집에서만 얻는 학생. 히나(드레스)·호시노(수영복) 등. 의상 이름 드레스와 같은 말이 아님 | [recruitment.md](guides/recruitment.md) |
| 익스 | 난이도 EXTREME. 순서는 EXTREME → INSANE → TORMENT → LUNATIC | [beginner.md](guides/beginner.md) |
| 걍클 / 걍클고 | "그냥 클리어 (가자)". 점수·순위와 상관없이 클리어만 하면 됨. 학생 이름이 아님 | user-feedback (2026-10-22) |
| 설거지 / 설거지 파티 | 앞 파티가 남긴 보스 체력을 다음 파티로 마저 처리하는 것, 또는 그 파티. "루나틱 설거지에서 ○○ 안 쓰는 파티"는 뒤쪽 파티 구성을 묻는 말 | [gregorius.md](raids/gregorius.md) |
| 침수 | 컷이 올라가 어떤 난이도 클리어 점수가 한 등급 아래(플래티넘 → 골드 등)로 밀려나는 것. 등급 기준이 서버마다 달라 판정도 서버별 | [beginner.md](guides/beginner.md) |
| 천장 | 모집 횟수를 채우면 픽업 학생을 확정으로 얻는 장치. 지금은 스택 200개 | [recruitment.md](guides/recruitment.md) |
| 토토인 / 토인인 | 대결전 세 장갑의 최고 난이도 구성. 토토인은 TORMENT 둘·INSANE 하나(일본 서버 S27부터), 토인인은 TORMENT 하나·INSANE 둘(그 전). "토인인"은 학생·보스 이름이 아님 | [beginner.md](guides/beginner.md) |
| 속성 / 3속성 (대결전) | 대결전에서 속성은 장갑별 전투 하나. 3속성은 그 시즌의 세 장갑 전부. 순위·플래티넘은 세 장갑 점수 합이라 "3속성 플레 조합"은 세 장갑 파티를 묻는 말이고 학생 속성 구성이 아님 | [beginner.md](guides/beginner.md) |
| 일섭 / 한섭 | 일본 서버 / 한국 서버. 사이트 시즌 기록은 일섭 기준 | [beginner.md](guides/beginner.md) |
| 택틱 | 편성과 운영 방식. "고즈 인세인 택틱"은 그 난이도를 깨는 파티를 묻는 말 | [beginner.md](guides/beginner.md) |
| 방깎 | 적 방어력 감소. "방깎 요원"은 이 디버프를 맡는 학생 | [stat_guide.md](guides/stat_guide.md) |
| 장판 | 바닥에 깔아 범위 안에 있는 동안 걸리는 버프·디버프. 같은 계열 다른 스킬과 겹침 | [stat_guide.md](guides/stat_guide.md) |
| 종전시 | 종합전술시험. "이번 종전시 조합"은 지금 열린 종합전술시험 회차의 편성을 묻는 말이고 대결전이 아님 | [content_guide.md](guides/content_guide.md) |
| 특임 / 경던 | 특별의뢰 / 그중 활동 보고서가 나오는 거점 방어 | [bounty_commission_scrimmage.md](guides/bounty_commission_scrimmage.md) |
| 전N (전무 N성) | 전용무기 N성. "노조미 전3" = 노조미 전용무기 3성. "N성"만 쓰면 학생 성급, "N파티"는 파티 수 | [beginner.md](guides/beginner.md) |
