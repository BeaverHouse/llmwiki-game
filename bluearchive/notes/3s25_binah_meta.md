## 개요

비나는 학생들이 강해진 현재는 정말 쉬운 보스에요. 약점 딜러와 방어력 감소만 챙기면 충분해요.  
그래서 거의 딜러 1자리만 바뀌고 나머지 파티원은 돌려쓰는 것도 가능했어요. 자세한 보스 수치는 [비나 문서](../raids/binah.md)를 참고하세요.

## 메인 딜러

해당 총력전 시점 가장 강한 딜러가 사용돼요. 확정 치명이면 좋지만, 리트라이로 해결할 수도 있어요.

| 장갑 (약점)     | 주 딜러            |
| --------------- | ------------------ |
| 경장갑 (폭발)   | **히나(드레스)**   |
| 특수장갑 (신비) | **아리스(메이드)** |
| 탄력장갑 (진동) | **미카(수영복)**   |

## 고정 멤버

**방어력 감소(방깎)와 코스트 관련 학생**이 거의 고정이에요.

| 학생             | 역할                                                                                    | 설명                                                                            |
| ---------------- | --------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------- |
| **마키**         | 노말스킬 **방깎**                                                                       | 비나의 높은 방어를 EX 방어력 감소와 조합하면 최대치로 깎을 수 있어요.           |
| **칸나(수영복)** | EX스킬 **방깎**                                                                         | 마키와 함께 방어력 감소 요원이에요.                                             |
| 키사키           | EX데미지 버프, 코스트 회복력                                                            | EX 딜러의 피해량을 크게 높여 줘요.                                              |
| 나기사(수영복)   | EX·패시브·서브 삼중 치명 데미지 버프 + **코스트 과부하**, 노말스킬 적 치명 데미지 저항↓ | 데미지 버프와 함께 코스트 과부하로 코스트를 당겨쓸 수 있어 타임어택에 적합해요. |
| 시로코(수영복)   | EX **방깎**, 노말스킬 전투시작 코스트 감소, 코스트 회복력                               | 코스트 관련 옵션이 빠른 공략에 유리하고, 방어력 감소도 가능해요.                |
| 호시노(무장)     | 서브 스킬 **방깎** + 탱커                                                               | 비나의 공격을 혼자 받을 수 있고 방어력 감소도 있어요.                           |

## 아로나 코멘트

- 시즌 한 줄: 약점 딜러 + 방어력 감소 학생 + 버퍼로 일반적인 구성을 하면 돼요. 너무 쉬워서 더 경쟁이 치열할 수도 있어요.
- Top 5 파티: 메인 딜러 + 칸나(수영복) + 나기사(수영복) 정도가 채용률이 매우 높았고, 나머지는 그래도 유동적인 것 같네요!
