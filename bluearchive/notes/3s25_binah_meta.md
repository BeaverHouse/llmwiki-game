## 개요

비나는 학생들이 강해진 지금은 정말 쉬운 보스예요. 약점 딜러와 방어력 감소만 챙기면 돼서 딜러 한 자리만 바꾸고 나머지 파티원은 돌려썼어요. 보스 수치는 [비나 문서](../raids/binah.md)에 있어요.

## 메인 딜러

시즌 당시 가장 강한 약점 딜러를 썼어요.

| 장갑 (약점)     | 주 딜러        |
| --------------- | -------------- |
| 경장갑 (폭발)   | 히나(드레스)   |
| 특수장갑 (신비) | 아리스(메이드) |
| 탄력장갑 (진동) | 미카(수영복)   |

## 고정 멤버

방깎과 코스트 학생이 거의 고정이었어요.

| 학생           | 역할                                                                   | 설명                                                   |
| -------------- | ---------------------------------------------------------------------- | ------------------------------------------------------ |
| 마키           | 노말 방깎                                                              | EX 방깎과 겹쳐 비나의 높은 방어를 최대치로 깎아요.     |
| 칸나(수영복)   | EX 방깎                                                                | 마키와 함께 방깎을 맡아요.                             |
| 키사키         | EX 대미지 버프, 코스트 회복력                                          | EX 딜러의 피해를 크게 올려요.                          |
| 나기사(수영복) | EX·패시브·서브 치명 대미지 버프, 코스트 과부하, 노말 적 치명뎀저항 감소 | 코스트를 당겨써서 타임어택에 맞아요.                   |
| 시로코(수영복) | EX 방깎, 노말 개전 코스트 감소, 코스트 회복력                          | 코스트 옵션으로 공략을 당기고 방깎도 보태요.           |
| 호시노(무장)   | 서브 방깎, 탱커                                                        | 비나의 공격을 혼자 받아요.                             |

## 아로나 코멘트

- 시즌 한 줄: 약점 딜러에 방깎 학생과 버퍼를 붙인 평범한 구성이었어요. 너무 쉬워서 오히려 경쟁이 더 치열했을지도 몰라요.
- Top 5 파티: 메인 딜러, 칸나(수영복), 나기사(수영복)는 채용률이 매우 높았고 나머지 자리는 꽤 유동적이었어요.
