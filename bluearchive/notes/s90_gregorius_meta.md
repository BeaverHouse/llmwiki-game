## 개요

플래티넘 20,000명 중 토먼트는 11,889명, 루나틱은 8,111명이었어요. 순위는 난이도와 상관없이 점수순이라 1~8,111위가 루나틱, 8,112~20,000위가 토먼트였고, 인세인으로는 플래티넘에 들 수 없었어요. 8,000위와 10,000위 사이에서 점수가 크게 끊기는 건 컷 급락이 아니라 이 난이도 경계예요. 직전 드럼통 게 루나틱이 188명이었던 것과 비교하면 난이도 차이가 컸어요.

그레고리오는 스트라이커 공격력을 깎아서 원래 스페셜 딜러가 유리한 보스예요([그레고리오 문서](../raids/gregorius.md)). 감소가 40%뿐인 토먼트에서는 히나(드레스) 메인 딜이 순위 경쟁에 유리했고, 70%로 늘어나는 루나틱은 의도대로 스페셜 딜러가 중심이 되어 미사키(수영복)를 메인 딜러로 많이 썼어요.

## 토먼트 (11,889명) - 스트라이커 중심

11,759명(98.9%)이 1파티였고 최다 조합 하나가 8,402명(70.7%)이라 대부분이 같거나 비슷한 파티로 경쟁했어요. 40% 감소로는 버프를 몰아 받은 히나(드레스)의 화력을 막지 못해서 스페셜 딜러보다 빨랐어요.

| 학생           | 채용률 | 역할                                                                                                                 |
| -------------- | ------ | -------------------------------------------------------------------------------------------------------------------- |
| 히나(드레스)   | 91.8%  | 메인 딜러                                                                                                            |
| 호시노(수영복) | 99.1%  | 폭발 서포터: 공격력 버프 + 폭발 특효 가산                                                                            |
| 키사키         | 97.3%  | EX 딜을 늘려 주는 공무원 버퍼                                                                                        |
| 후우카(새해)   | 71.4%  | 아군 EX 코스트 최대 50% 감소 + 치명 대미지 증가로 사이클을 당겨요.                                                   |
| 미네           | 100.2% | 탱커 겸 디버프 누적. EX+노말로 디버프 4개를 쌓아(학생 중 최다) 그레고리오의 디버프 기믹을 채워요.                    |
| 호시노(무장)   | 91.6%  | 미네와 같이 탱커를 맡아 힐러 없이 토먼트 공격을 버티고, 디버프 기믹도 보조해요.                                       |

## 루나틱 (8,111명) - 스페셜 중심

스트라이커 공격력 감소가 70%가 되고 체력도 늘어서 스페셜 딜러가 중심이 됐어요.

- 미사키(수영복) 102.1%: 스페셜 폭발 딜러예요. 명중 수치가 높아 성가대에게 빗나가지 않고, EX가 대상의 해로운 효과 개수에 비례해 피해가 커져요.
- 나기사 99.6%: 스페셜 폭발 딜러예요. 파티 안정성을 높이고 EX 딜도 준수하며 방깎과 치명 대미지 버프도 있어요.
- 호시노(무장) 99.5%: 토먼트와 같은 역할이에요.

버퍼도 스페셜 딜러를 받치는 쪽으로 바뀌었어요.

| 구간        | 채용                                                          | 이유                                                                                                                       |
| ----------- | ------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| 상위 ~500위 | 미나·나구사(수영복)·레나                                      | 나구사(수영복)·레나 EX가 스페셜 학생 전용 버프(폭발 특효·치뎀·공버프)라 스페셜 딜을 끌어올리고, 미나가 디버프 개수를 채워요. |
| 501위~ 대중 | 마리(아이돌)·사쿠라코(아이돌)·미네·히비키·사키(수영복)·코하루 | 위 학생들이 대부분 신규라서 기존 학생으로 안정적으로 클리어한 경우가 많았고, 보통 2파티 이상이에요.                         |

| 학생                               | 토먼트 | 루나틱 | 왜                                                                                                          |
| ---------------------------------- | ------ | ------ | ----------------------------------------------------------------------------------------------------------- |
| 키사키·호시노(수영복)·히나(드레스) | 100%   | 6~33%  | 토먼트 스트라이커 메타 학생이고, 루나틱에서는 후속 파티 정도로만 썼어요.                                       |
| 후우카(새해)                       | 71.4%  | 4.6%   | 스트라이커 파티 사이클을 줄이는 역할이라 루나틱에서는 급감해요.                                                |
| 미사키(수영복)                     | 0.1%   | 102.1% | 토먼트에서는 기록이 밀렸지만 루나틱에서는 거의 필수였어요.                                                     |
| 마리(아이돌)                       | 0%     | 84.5%  | 토먼트는 미네 + 호시노(무장)로 1파티가 돼서 힐이 필요 없었고, 루나틱에서 2파티 이상이면 채용률이 매우 높았어요. |

## 미네·미나가 없을 때

디버프 개수를 채우는 미네와 미나는 다른 학생으로 바꾼 기록이 거의 없어요. 두 학생을 조력자까지 모두 빼고 조회한 결과예요.

- 둘 다 없음: 루나틱 클리어 기록은 0건이에요. 토먼트도 플래티넘(20,000위) 밖에서야 사키(수영복)·마리(아이돌)·호시노(무장)·나구사(수영복) / 히비키 + 미사키(수영복) 조력 같은 편성이 보여요. 둘 중 한 명은 있어야 해요.
- 미나만 없음 (루나틱): 최고 기록은 1,898위의 2파티예요. 1파티는 미네·사키(수영복)·레나·마리(아이돌) / 나기사 + 미사키(수영복) 조력, 2파티는 사쿠라코(아이돌)·호시노(무장)·코하루·나구사(수영복) / 이치카(수영복)·미노리였어요. 미나 자리는 미네가 채우고, 1파티로 못 끝내 2파티로 나눴어요.
- 미네만 없음 (루나틱): 1위부터 미나·호시노(무장)·레나·나구사(수영복) / 미사키(수영복)·나기사 1파티라 기록 손실이 없어요.
- 미네만 없음 (토먼트): 미네를 뺀 토먼트 기록은 플래티넘 밖의 미나 스페셜 편성뿐이고, 상위권 히나(드레스) 편성에서 미네를 대체한 기록은 없어요.

루나틱은 미나가, 토먼트 히나(드레스) 편성은 미네가 더 중요해요.

## 아로나 코멘트

- 시즌 한 줄: 토먼트에서는 드레스(히나) + 미네/호시노(무장) 2탱 조합이, 루나틱은 미사키(수영복) 중심 스페셜 파티가 핵심이었어요.
- 핵심 캐릭터(토먼트): 스트라이커 공격력 감소 수치가 40%밖에 되지 않고, 드레스(히나) + 미네/호시노(무장) 2탱 조합으로 스트라이커에 버프를 몰아 주는 조합이 더 빨랐어요.
- 핵심 캐릭터(루나틱): 루나틱에서는 원래대로 스페셜 딜러가 핵심이었고, 미사키(수영복)·나기사가 메인으로 활약했어요.
- Top 5 파티(토먼트): 고점 조합은 사실상 하나로 고정이었고, 나머지 파티도 약간의 변형만 있었어요.
- Top 5 파티(루나틱): 상위권은 스페셜 전용 버퍼(나구사(수영복)·레나)로 딜을 끌어올렸고, 대중은 접근성 높은 학생으로 안정적 클리어를 노렸어요.
- 파티 비율(루나틱): 높은 순위의 선생님들은 1파티 클리어를 했고, 다른 선생님들은 주로 2파티 클리어를 노렸네요!
