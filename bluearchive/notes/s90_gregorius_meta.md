# 총력전 S90 그레고리오 — 픽률·메타 리포트

규모: **토먼트 11,889명 / 루나틱 8,111명**. 직전 신보스 S89(루나틱 188명)와 정반대로 루나틱이 대중화된 시즌이다. 박제 파티 49개 제외(하한선).

**한 줄 정의: 스트라이커 공격력 감소가 토먼트 40%→루나틱 70%로 뛰면서, 딜의 축이 스트라이커에서 스페셜로 넘어간 시즌. 그래서 두 난이도가 완전히 다른 로스터를 쓴다.**

보스 기본 정보는 [그레고리오 문서](../raids/gregorius.md) 참조 — 경장갑(폭발 약점), 스트라이커에게 공격력 감소를 걸어 원래는 **스페셜 딜러가 유리한 보스**다. 이 시즌의 모든 것이 이 디버프 수치가 난이도별로 얼마냐에서 갈린다.

## 토먼트 (11,889명) — 왜 스트라이커 딜러인가

- **11,759명(98.9%)이 1파티 클리어**, 최다 조합 하나가 8,402명(70.7%)으로 사실상 정답 한 벌이 공유됐다.
- **스페셜 접대 보스인데 딜러가 스트라이커(히나(드레스))인 게 이 토먼트의 핵심.** 토먼트는 스트라이커 공격력 감소가 40%에 그쳐, 스트라이커 딜러 한 명에게 버프를 몰아주는 편이 스페셜 딜러를 쓰는 것보다 클리어 타임이 빨랐기 때문이다. 정답 조합이 그 구조 그대로다:

| 학생                | 채용률    | 킷 × 역할                                                             |
| ------------------- | --------- | --------------------------------------------------------------------- |
| 히나(드레스)        | 91.8%     | 폭발 스트라이커 딜러(집중 사격) — 버프를 몰아받는 딜 축               |
| 호시노(수영복)      | 99.1%     | 폭발 서포터 — 광역 공격력 버프 + 폭발 특효 가산으로 스트라이커 강화   |
| 키사키              | 97.3%     | 딜 증가 버퍼                                                          |
| 후우카(새해)        | 71.4%     | 아군 EX 코스트 최대 50% 감소 + 치명 대미지 증가 — 딜 사이클 가속·버프 |
| **미네**            | 100.2%    | 폭발 탱커 겸 **디버프 셔틀** — EX+노말로 디버프 4개를 쌓아(학생 중 최다) 그레고리오의 '디버프 개수 기믹'을 홀로 채운다 |
| 호시노(무장)        | 91.6%     | 신비 탱커(엄폐) — 성가대 공격을 버틴다                               |

**이 토먼트에는 두 번째 축이 있다: 디버프 개수 기믹.** 그레고리오는 본체에게 걸린 디버프 수를 최적으로 유지하면 받는 대미지가 크게 오른다. 그래서 딜러(히나(드레스))만큼이나 **디버프를 대량 공급하는 미네**가 정답 조합의 숨은 핵심이다. 즉 토먼트는 "스트라이커 1명에 버프·디버프를 몰아주는" 시험이다.

## 루나틱 (8,111명) — 스페셜로 회귀

스트라이커 공격력 감소가 **70%로 뛰면 스트라이커 딜이 반토막** 나므로, 감소를 받지 않는 스페셜 딜러로 축이 넘어간다. 그래서 전 구간 공통 코어가 토먼트와 완전히 다르다:

- **미사키(수영복) 102.1%** — 스페셜 폭발 딜러. EX가 **대상의 해로운 효과 개수에 비례해 대미지**라, 디버프를 계속 쌓는 그레고리오와 시너지가 크다.
- **나기사 99.6%** — 스페셜 폭발 딜러(경장갑 상대 방깎 내장).
- **호시노(무장) 99.5%** — 신비 탱커.

**상위권과 대중이 다른 학생을 쓰는 이유도 스페셜 축에서 나온다.** 스페셜 딜러를 극대화하려면 스페셜 전용 버퍼가 필요한데, 상위권은 그것을 쓴다:

| 구간        | 채용                                                          | 이유                                                                                                                                                                         |
| ----------- | ------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 상위 ~500위 | 미나·나구사(수영복)·레나                                      | **나구사(수영복)·레나 EX가 스페셜 학생 전용 버프**(폭발 특효·치뎀·공버프)로 스페셜 딜러 딜을 끌어올리고, 미나는 EX가 공격력·명중·회피 3종 디버프라 **디버프 개수 기믹(본체에 디버프를 최적 수로 쌓으면 받뎀 증가)을 채운다** — 토먼트의 미네와 같은 역할. 저비용 고점 설계 |
| 501위~ 대중 | 마리(아이돌)·사쿠라코(아이돌)·미네·히비키·사키(수영복)·코하루 | 보유 접근성이 높은 학생으로 같은 난이도를 안정 통과                                                                                                                          |

상위권 조합은 스페셜 버퍼로 딜 상한을 끌어올리는 설계, 대중 조합은 접근성 우선. 두 집단이 섞이지 않는다.

## 토먼트↔루나틱 완전 분리 — 원인은 하나

같은 학생이 난이도에 따라 켜지고 꺼지는데, 원인은 전부 **스트라이커 vs 스페셜 축 전환** 하나다.

| 학생                               | 토먼트 | 루나틱 | 왜                                                      |
| ---------------------------------- | ------ | ------ | ------------------------------------------------------- |
| 키사키·호시노(수영복)·히나(드레스) | 100%   | 6~33%  | 스트라이커 축용 딜러·버퍼 → 루나틱에선 불필요           |
| 후우카(새해)                       | 71.4%  | 4.6%   | 스트라이커 축 지원(코스트·치뎀 버프) → 축이 바뀌며 이탈 |
| 미사키(수영복)                     | 0.1%   | 102.1% | 스페셜 딜러 → 70% 감소 구간의 새 딜 축                  |
| 마리(아이돌)                       | 0%     | 84.5%  | 루나틱 스페셜 체제의 힐/서포트                          |
