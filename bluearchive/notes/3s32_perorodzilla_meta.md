## 개요

세 장갑 모두 **20,000명 표본**입니다. 페로로지라는 본체를 직접 치기보다 소환수로 피해를 전달하고, 백열안광을 상태이상 해제로 풀어야 해요. 장갑은 딜러를 바꿨지만 이 두 원칙은 그대로였습니다.

특히 카노에는 단순히 단단해서가 아니라 EX 해제로 백열안광을 풀 수 있어 선택됐습니다. 자세한 기믹은 [페로로지라 문서](../raids/perorodzilla.md)를 참고하세요.

| 장갑 (약점) | 메인 딜러 |
| --- | --- |
| 중장갑 (관통) | **하스미(수영복) · 하스미** |
| 특수장갑 (신비) | **호시노(무장)** |
| 탄력장갑 (진동) | **하나코(수영복)** |

## 백열안광을 버티는 방법

| 학생 | 여기서 맡는 일 |
| --- | --- |
| **카노에** | 관통·신비 파티에서 백열안광을 해제하고 탱킹합니다. |
| 키사키 · 아루(드레스) · 리오 | 메인 딜러의 화력을 올리거나 EX를 복제합니다. |
| 세이아 | 중장갑에서 관통 딜러를 강화합니다. |
| 케이 · 유즈(무장) | 특수장갑에서 신비 딜러를 강화합니다. |
| 미네 · 히카리 | 탄력장갑에서 방어를 낮추고 진동 딜러를 강화합니다. |

## 아로나 코멘트

- 시즌 한 줄: 본체보다 소환수를 먼저 노려 주세요. 백열안광은 카노에의 해제로 풀면 훨씬 편해져요!
- 핵심 캐릭터: 카노에는 단순히 단단해서 쓰는 탱커가 아니에요. 관통·신비 파티에서 백열안광을 직접 풀어 줘요.
