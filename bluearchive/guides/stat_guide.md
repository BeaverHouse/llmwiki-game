## 기본 스탯

- 공격력: 주는 데미지가 늘어요.
- 방어력: 받는 데미지가 `방어력 / (방어력 + 1666)`만큼 줄어요.
- HP: 0이 되면 전투불능이 되어 퇴각해요.
- 치유력: HP 회복량과 보호막 수치를 올려요.

## 명중·회피

- 명중 수치: 공격이 명중할 확률을 올려요.
- 회피 수치: 공격을 회피할 확률을 올려요.

## 치명타

- 치명 수치: 크리티컬 확률을 올려요.
- 치명 저항 수치: 적의 치명 수치에서 빼요. 보스마다 달라요.
- 치명 데미지: 크리티컬 데미지 배율이고 기본 200%예요.
- 치명 데미지 저항: 적의 치명 데미지에서 빼요.

## 안정·사거리

- 안정 수치: 데미지 편차를 정해요. 최소치는 `안정값 / (안정값 + 1000) + 0.2`, 최대치는 1이에요.
- 사거리: 공격 가능한 거리예요. 스페셜 학생은 모두 1000이에요.

## CC

군중 제어 강화력은 기절·공포·도발 같은 상태이상의 발동 확률을 올려요. 호드와 호버크래프트에서는 이에 비례해 상태이상 누적 시간이 늘어요.

## 지형 적성

지형은 시가지·야외·실내이고 학생마다 적성이 달라요. 전용무기 3성에서 하나 이상이 올라요. 기본으로 SS인 학생은 없고, 전용무기 3성으로 S가 SS가 되는 경우가 많아요.

적성은 데미지 배율과 엄폐 확률을 같이 정해요. 엄폐한 학생이 공격을 막을 확률과, 엄폐한 적을 무시하고 맞힐 확률이 아래 표를 따라요. 그래서 적성이 낮으면 주는 데미지가 줄고 엄폐로 막는 공격도 줄어요. 탱커와 MG 학생은 대부분 엄폐하지 않아요.

| 적성 등급 | 데미지 배율 | 엄폐 성공·엄폐 무시 확률 |
| --------- | ----------- | ------------------------ |
| D         | 0.8배       | 0%                       |
| C         | 0.9배       | 15%                      |
| B         | 1.0배       | 30%                      |
| A         | 1.1배       | 45%                      |
| S         | 1.2배       | 60%                      |
| SS        | 1.3배       | 75%                      |

## 속성 특효

약점 속성 공격은 기본 200% 데미지이고, 폭발·관통·신비·진동 특효 스탯으로 더 올라가요.

## 버프·디버프 중첩

- 고정 수치나 퍼센트로 스탯을 올리고 내리는 효과는 대부분 합연산이에요. 같은 스탯 버프를 여러 개 받으면 하나 더할 때 오르는 비율이 줄고, 방어력 감소 같은 디버프는 겹칠수록 효과가 커져요.
- 그래서 딜러가 이미 가진 버프와 다른 종류를 붙여야 효율이 좋아요. 카즈사는 기본·강화·서브 스킬이 모두 공격력 증가라 히마리 같은 공격력 버프 효율이 떨어져요.
- 그레고리오의 받는 대미지 증가처럼 곱연산인 효과도 있어요.
- 같은 계열(EX·기본·강화·서브) 스킬의 같은 효과는 겹치지 않고 나중에 건 쪽으로 덮어써요. 아카네와 칸나(수영복)의 방어력 감소는 둘 다 EX라 나중 것만 남아요. 마키의 방어력 감소는 기본 스킬이라 둘 중 누구와도 겹쳐요.
- 같은 계열이어도 학생이 자기에게 거는 버프와 다른 학생이 걸어 주는 버프는 겹쳐요. 호시노(수영복)의 버프, 하나코(수영복)의 방어력 감소 같은 장판 효과도 다른 스킬과 겹쳐요. 마키와 하나코(수영복)는 둘 다 기본 스킬 방깎이지만 하나코 쪽이 장판이라 겹쳐요.
- 같은 서브 스킬 효과를 가진 스페셜 둘을 함께 넣으면 뒤 슬롯 학생의 서브 스킬이 남아요. 서브 스킬은 전투 시작에 앞 슬롯부터 걸려서예요.

## 전용무기 성급

전용무기(고유무기)는 학생이 5성이 되면 열려요. 커뮤니티에서는 "전3", "전무 4성"처럼 줄여 불러요([용어집](../glossary.md)). 현재 4성까지 있어요.

| 성급 | 최대 레벨 | 열리는 효과 |
| --- | --- | --- |
| 1성 | 30 | 전용무기 장착. 공격력·최대 체력·치유력 중 일부가 오름 |
| 2성 | 40 | 강화 스킬(2스킬)이 강화됨. 보통 원래 효과에 능력치가 더 붙음 |
| 3성 | 50 | 세 지형 중 하나의 적성이 오름 |
| 4성 | 60 | 스트라이커: 약점을 찌르는 적에게 주는 속성 효율 10% 증가 / 스페셜: 최대 코스트 0.5 증가 |

전3과 전4의 데미지 차이

- 스트라이커: 약점 속성 효율 10%와 무기 레벨 상한(50→60)만큼의 능력치가 붙어요. 약점이 아닌 적에게는 속성 효율 증가가 없어요.
- 스페셜: 4성 효과는 최대 코스트 0.5 증가라서, 데미지 차이는 무기 레벨 상한에서 오는 능력치뿐이에요.
- 학생별 수치는 계산 도구로 봐요. 단계별 엘레프·엘리그마 수는 [엘리그마 문서](eligma.md)에 있어요.
