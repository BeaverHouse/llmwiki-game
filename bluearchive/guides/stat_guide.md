# 블루 아카이브 스탯 가이드

블루 아카이브의 전투 스탯에 대한 설명입니다.

## 기본 스탯

1. 공격력: 주는 데미지가 증가합니다.
2. 방어력: 받는 데미지가 감소합니다. 방어력이 높으면 `방어력 / (방어력 + 1666) × 100%` 만큼 데미지가 감소합니다.
3. HP: 체력입니다. 0이 되면 전투불능 상태가 됩니다.
4. 치유력: HP 회복량과 보호막 수치에 영향을 줍니다.

## 명중/회피 스탯

1. 명중 수치: 공격이 명중할 확률에 영향을 줍니다.
2. 회피 수치: 공격을 회피할 확률에 영향을 줍니다.

## 치명타 스탯

1. 치명 수치: 크리티컬 발생 확률에 영향을 줍니다.
2. 치명 저항 수치: 적의 치명 수치에서 차감됩니다. 보스마다 다른 치명 저항을 가집니다.
3. 치명 데미지: 크리티컬 히트 시 데미지 배율입니다. 기본값은 200%입니다.
4. 치명 데미지 저항: 적의 치명 데미지에서 차감됩니다.

## 안정/사거리 스탯

1. 안정 수치: 데미지의 편차(최소~최대 범위)에 영향을 줍니다.

- 데미지 최소치 = `안정값 / (안정값 + 1000) + 0.2`
- 데미지 최대치 = 1
- 안정값이 높을수록 최소 데미지가 최대 데미지에 가까워집니다.

2. 사거리: 공격 가능한 거리입니다. 스페셜 학생은 일률적으로 1000입니다.

## CC 스탯

1. 군중 제어 강화력: 기절, 공포, 도발 등 상태이상이 발동할 확률에 영향을 줍니다.
   단, 호드와 호버크래프트에서는 이에 비례해 상태이상 누적 시간이 증가합니다.

## 지형 적성

블루 아카이브에는 시가지/야외/실내 3가지 지형이 있으며, 학생마다 적성이 다릅니다.

| 적성 등급 | 데미지 배율 |
| --------- | ----------- |
| D         | 0.8배       |
| C         | 0.9배       |
| B         | 1.0배       |
| A         | 1.1배       |
| S         | 1.2배       |
| SS        | 1.3배       |

전용무기 3성 달성 시 지형 적성 중 하나 이상이 상승합니다.

## 속성 특효

약점 속성 공격 시 기본 200% 데미지가 적용되며, 특효 스탯으로 이를 증가시킬 수 있습니다.

- 폭발 특효
- 관통 특효
- 신비 특효
- 진동 특효

전용무기 4성 스트라이커는 해당 속성 특효가 10% 증가합니다.
