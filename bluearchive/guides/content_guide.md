# 블루 아카이브 컨텐츠 가이드

YouTube 검색 링크 생성 규칙: `https://www.youtube.com/results?search_query={키워드를+로 연결}`
사용자 질문에 맞게 키워드를 조합하여 URL을 직접 생성할 것.

## 종합전술시험 (合同火力演習)

3개 파티로 각각 다른 전투를 1번씩, 총 3번 클리어하는 시험. 조력자 제외 학생 중복 불가.
3단계부터 특수 기믹이 추가되고, 합계 스코어로 보상(코인)이 결정됩니다.
최대 난이도인 4단계를 최대한 많이 클리어하여 높은 코인을 획득하는 것이 목표입니다.

### 종류

| 한국어 | 일본어   | 설명                        |
| ------ | -------- | --------------------------- |
| 사격   | 射撃演習 | 타겟 적을 처치              |
| 돌파   | 突破演習 | 방어 진지 돌파              |
| 방어   | 防御演習 | 일정 시간 내 대량의 적 처치 |
| 호위   | 護衛演習 | 호위 대상 보호              |

### 검색 키워드

- 한국어: 블루아카이브, 종합전술시험, 4-4-4
- 일본어: ブルアカ, 合同火力演習, 4-4-4
- 특정 시험: {사격/돌파/방어/호위} 또는 {射撃演習/突破演習/防御演習/護衛演習}

## 제약해제결전 (制約解除決戦)

단계별로 보스가 강해지는 연속 전투. 구간: 1~24, 25~49, 50~74, 75~99, 100~124층.
97층까지 클리어하면 능력해방 재화 전부 획득 가능.
