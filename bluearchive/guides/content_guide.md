# 블루 아카이브 컨텐츠 가이드

YouTube 검색 링크는 `https://www.youtube.com/results?search_query={키워드를+로 연결}` 꼴로, 질문에 맞는 키워드를 골라 만듭니다.

## 종합전술시험 (合同火力演習)

세 파티로 서로 다른 전투를 한 번씩 클리어합니다. 조력자 말고는 학생을 겹쳐 쓸 수 없습니다. 3단계부터 특수 기믹이 붙고, 합계 점수로 코인 보상이 정해져서 최대 난이도인 4단계를 많이 깰수록 코인이 늘어납니다.

| 한국어 | 일본어   | 설명                        |
| ------ | -------- | --------------------------- |
| 사격   | 射撃演習 | 타겟 적을 처치              |
| 돌파   | 突破演習 | 방어 진지 돌파              |
| 방어   | 防御演習 | 일정 시간 내 대량의 적 처치 |
| 호위   | 護衛演習 | 호위 대상 보호              |

검색 키워드

- 한국어: 블루아카이브, 종합전술시험, 4-4-4
- 일본어: ブルアカ, 合同火力演習, 4-4-4
- 특정 시험: {사격/돌파/방어/호위} 또는 {射撃演習/突破演習/防御演習/護衛演習}

## 제약해제결전 (制約解除決戦)

최대 10명으로 층별 보스에 도전합니다. 진행 방식, 보상과 목표 층, 보스 기믹, 공략 영상은 [제약해제결전 입문과 99층 공략](final_restriction_release.md)에 있습니다.

| 한국어      | 일본어       | 장갑                 |
| ----------- | ------------ | -------------------- |
| 세트의 분노 | セトの憤怒   | 특수장갑/경장갑 교대 |
| 호크마      | コクマー     | 중장갑/특수장갑      |
| 티페레트    | ティファレト | 탄력장갑/중장갑      |

검색 키워드

- 한국어: 블루아카이브, 제약해제결전, {보스명}, {층수}
- 일본어: ブルアカ, 制約解除決戦, {보스명 일본어}, {층수}階

## 전술대항전 (戦術対抗戦)

다른 선생님이나 NPC와 겨뤄 순위를 올리는 PvP 콘텐츠입니다.

검색 키워드

- 한국어: 블루아카이브, 전술대항전
- 일본어: ブルアカ, 戦術対抗戦
