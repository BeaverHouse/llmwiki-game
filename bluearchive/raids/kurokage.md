# 쿠로카게 (Kurokage)

## 기본 정보

- **장갑 (총력전 기준)**: 탄력장갑 (진동 약점)
- **공격 속성 (인세인 이상)**: 신비 → 특수장갑 학생 2배 피해
- **특징**: 위압, 광역 공격, 보호막 관통

## 기믹

- **위압**: 특정 공격이 위압 수치를 쌓고, 쌓일수록 최대 체력이 줄어듭니다. 회복하면 위압 수치가 줄어듭니다. 50% 이상 잠식되면 혼란에 걸려 아군을 공격합니다.
- **묘귀의 편린**: 편린은 쿠로카게와 체력을 공유하고, 약점 공격으로 그로기 수치가 쌓입니다. 그로기가 되면 4개의 편린으로 갈라지며 모든 데미지를 치명타로 받습니다.
- **보호막 관통**: 모든 공격이 보호막을 관통해 보호막 학생은 쓰지 않습니다.

## 추천 학생 유형

- **힐러**: 위압 해제에 필수
- **방어력 감소** 스킬: 여럿에 걸 수 있으면 더 좋습니다.
- **광역** 딜러
